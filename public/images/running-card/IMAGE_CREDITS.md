- `c2pa.actions.v2` → `c2pa.created`, `softwareAgent: { name: "ChatGPT", version: "gpt-image" }`
- `digitalSourceType: http://cv.iptc.org/newscodes/digitalsourcetype/trainedAlgorithmicMedia`
- `claim_generator_info.name: OpenAI Media Service API`
- 서명 인증서 주체: `OpenAI OpCo, LLC` / `OpenAI Media Service`(발급 SSL.com C2PA ICA R1)

## 표식 제거 편집본 14장 복원 (2026-10-08)

위 표식 제외 결정 후 운영자가 제공한 `러닝카드-표식지우기/GPT 지시서.txt`에 따라 Codex의 내장 OpenAI 이미지 편집 도구로 각 PNG를 따로 편집했다. 모델 세부 버전은 도구가 제공하지 않아 불명이다. 입력은 해당 인물 원본 또는 바로 앞 편집본 한 장뿐이며, 다른 인물 이미지를 참조하지 않았다.

프롬프트 공통: 표식만 지우고 인물·자세·구도·옷색·배경·조명·크기를 유지. 옷·신발·양말에 로고·글자·배지·갈고리·세 줄·N/V·물결형 스포츠 브랜드 표식을 넣지 않는다. 반복 편집에서 남는 신발 패널·혀 배지는 같은 색의 단순한 무표식 니트 신발로 지정했다. 일부 옷·신발 질감과 디테일은 원본과 달라졌다.
