# 세계 7개 대회 사진 자산

사진은 서로 다른 개최연도의 자료사진이다. 션의 실제 도전 장면이나 사용자의 개인 러닝 사진으로 표현하지 않는다. 도시 목록은 영화의 세계 7대 마라톤 도전을 소개하기 위한 구성이다.
