# 릴스 게시 캡션 초안

영화가 시작되기 전에, 나는 달렸다.

평소에도 달리긴 하는데, 주말엔 밖에 나가는 게 쉽지 않더라고요.
이번엔 런데이 쉘위런 시네마런 챌린지 덕분에 한 번 더 나가서 달렸어요.
누적 11.2km 미션을 마치고 완주 배지도 받았어요!

션의 세계 7대 마라톤 도전을 담은 영화 <쉘위런>의 개봉을 기다리고 있어요.
이번 러닝을 기념하고 싶어서 사이트도 만들고, 짧은 영상으로 담아봤어요.

다음 한 걸음, 같이 달릴까요?

- 런데이 앱에 적힌 필수 해시태그·계정 태그와 SNS 인증 제출 방법.
- 앱이 안내하는 인증 마감 시각과 인정되는 게시 형식.
- 위 링크의 실제 배포 상태.
