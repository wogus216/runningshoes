# 쉘위런 — 영화가 시작되기 전에, 나는 달렸다.

`/shall-we-run`의 실제 DOM을 캡처해 만드는 세로 릴스. 빠른 소개용 15초 편집본과 기존 34초 버전을 지원한다. 웹은 자연 스크롤, 영상은 같은 장면에 시간을 직접 공급한다. 별도의 영상 전용 UI를 복제하지 않는다.

## 제작

프로젝트 루트에서 Node.js 22+, Chrome, ffmpeg/ffprobe와 기존 설치된 sharp를 사용한다.

```sh
npm run build
node docs/running-card-harness/serve.mjs out 3028
```

다른 터미널에서:

```sh
node video/shall-we-run/render.mjs http://localhost:3028 /Users/kwonjaehyeon/Downloads/shall-we-run-production/15s 15
```

Chrome 경로를 바꾸려면 `SHALL_WE_RUN_CHROME` 환경변수를 지정한다. 캡처 모드(`?capture=1`)는 제작 도구용이며 일반 페이지에 옵션 UI를 노출하지 않는다.

## 산출물

- `15s/shall-we-run-reel-15s-1080x1920.mp4`: 빠른 소개용 H.264, 1080×1920, 30fps, 450프레임, 15초. 현재 무음본.
- `15s/encoded-video-contact-sheet.png`: 인코딩된 MP4에서 추출한 여섯 화면. 소스 장면 이미지와 픽셀 차이를 비교해 렌더 보고서에 기록한다.
- `shall-we-run-reel-1080x1920.mp4`: H.264, 1080×1920, 30fps, 1,020프레임, 34초. 현재 무음본.
- `shall-we-run-cover-1080x1920.png`: 제공 배지 전체와 챌린지명이 들어간 릴스 커버.
- `cover-preview-4x5.png`, `cover-preview-square.png`: 커버의 중앙 크롭 확인용. 실제 인스타그램 크롭 결과는 업로드 미리보기에서 확인한다.
- `storyboard-contact-sheet.png`: 여섯 장면 확인용 이미지.
- `scene-*s.png`: 시간별 1080×1920 정지 이미지.
- `web-*.png`, `render-report.json`: 네 화면 폭·자연 스크롤·장면 링크·모션 감소·JS 비활성 확인 기록.

배지 원본은 사용자가 제공한 `badge_shareImg.jpg`를 내용 변경 없이 `public/images/challenge/shall-we-run/badge-original.jpg`에 복사했다. 배지 속 인물은 사용자의 러닝 사진으로 표현하지 않는다. 세계 7개 대회 자료사진은 [photo-sources.md](./photo-sources.md)에 원본·촬영자·라이선스를 기록했다. 개인 촬영물·영화 포스터·레퍼런스 영상은 이번 버전에 포함하지 않았다.

런데이 앱 아이콘은 Apple의 런데이 앱 등록 정보(ID `1042937618`)에서 제공하는 512px 이미지를 내용 변경 없이 저장했다. 공식 앱 열기 주소는 `https://link.runday.co.kr/app`, 설치 링크는 해당 App Store와 Google Play 등록 페이지를 사용한다. 앱 화면이나 사용자의 기록 화면은 재현하지 않았다.

## 15초 편집

| 시간 | 내용 |
|---|---|
| 0–1.5초 | 영화가 시작되기 전에, 나는 달렸다. |
| 1.5–5초 | 쉘위런 소개와 세계 7개 대회 사진, 사진당 약 0.5초 |
| 5–8초 | 런데이 앱 아이콘, 참여 계기 → 조금 더 달렸다. |
| 8–12초 | 완주 배지 원본 전체와 누적 11.2km 미션 달성 |
| 12–15초 | 다음 한 걸음, 같이 달릴까요? 계정과 영화 개봉 정보 |

34초 버전은 마지막 인자를 생략하거나 `34`로 지정하고 기존 출력 폴더에 제작한다. 웹의 스크롤 장면 길이는 유지한다. 15초 편집은 필요한 구간을 골라 연결하며 배지의 읽기 시간을 4초 확보한다. 각 프레임은 DOM 변경 후 브라우저의 두 번의 페인트 주기를 기다린 뒤 캡처한다.

## 기존 34초 장면

| 시간 | 내용 |
|---|---|
| 0–3초 | 영화가 시작되기 전에, 나는 달렸다. |
| 3–10초 | 쉘위런, 션의 세계 7대 마라톤 도전, 우리는 왜 달리는가? 대회 사진과 이름이 1초마다 바뀐다. |
| 10–15초 | 주말에 나가기 쉽지 않았던 나의 경험 |
| 15–20초 | 런데이 앱 아이콘과 챌린지명. 앱에서 신청한 챌린지가 계기가 되어 조금 더 달렸다. |
| 20–27초 | 제공된 완주 배지 전체, 누적 11.2km 미션 달성 |
| 27–34초 | 다음 한 걸음으로의 초대, 영화 개봉 정보, 계정 |

원본 배지의 날짜는 2026.10.11. 11.2km는 누적 챌린지 목표이며 단일 러닝 거리·사용자의 전체 훈련 거리로 표현하지 않는다. 영화는 아직 보지 않았으므로 감상평을 넣지 않았다. 영화 소개·개봉 예정 정보는 사이트 하단의 출처와 2026.10.11 기록 맥락으로 남긴다.

## 게시 캡션 초안

[posting-caption.md](./posting-caption.md)를 참고한다. 필수 태그와 인증 제출 방법은 런데이 앱 안내가 제공된 뒤 확정한다.

릴스 업로드 시 커버를 지정하고 **계정 피드에서도 보이도록 게시 설정**을 확인한다. 게시 미리보기에서 배지·챌린지명 크롭과 배지 장면(15초본 8–12초, 34초본 20–27초)의 UI 겹침을 확인한다. 공개 게시 후 계정 피드에서 실제 노출을 확인하고 앱에 요구되는 제출을 완료한다. 산출물 제작·사이트 배포는 SNS 응모 완료를 의미하지 않는다.
