젤 8회 팝업과 보급 요약표는 제거했다. 사이트의 8회 보급 예시는 유지하며, 영상은 정기적인 보급 체크를 안내한다. GPX 고도 변화는 실측 노면 경사나 개인의 피로 예측이 아니다.

`npm run render:course`는 v3 마스터와 Instagram용 제한 범위 BT.709 파일을 생성한다. 전달할 파일은 `output/sonkeechung-2026-reel-v3-instagram.mp4`이며, 마스터 파일과 구분한다. 표지는 `npm run still:course`로 생성한다.

게시 캡션과 첫 댓글은 이 디렉터리의 v3 파일을 사용한다. 사진·지도 이용 표기를 포함한 첫 댓글을 함께 게시한다. 음악은 사용자가 Instagram에서 추가한다.

게시 전 연결 확인: 2026-11-02 확인 당시 공개 코스 주소는 HTTP 404였다. 사이트 배포 및 프로필 링크를 아래 코스 페이지로 연결한 뒤 게시한다. 인스타그램 게시·예약 및 프로필 수정은 수행하지 않았다.
