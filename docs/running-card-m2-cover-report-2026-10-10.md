# M2 표지 구현·QA 기록 — 2026-10-10

## 구현

확정 계획 `running-card-m2-cover-plan-2026-10-10.md`를 적용했다. 저장·열기·공유의 첫 장만 단일 원형 메달로 바뀐다. 중앙에는 판정된 인물 표식 하나가 들어간다. 얇은 이중 테, 모따기와 두께, 밀링 옆면, 주황 직조 리본, 완만한 볼록 금속 바탕과 둥근 경사면의 부조를 사용한다.

`medal-cover-renderer.js`는 표지 전용 씬을 렌더하고 캔버스 복사 후 씬·재질·텍스처·환경맵·렌더러를 해제한다. 분석 씬을 공유하지 않는다. 망치·월계관·독수리의 큰 도상 보정도 이 모듈 안에만 있다. WebGL이 없으면 같은 원판·표식의 CPU 부조를 그린다. 사용자 기록은 렌더러에 전달하지 않는다.

기존 분석 이미지, 웹 결과, 입력 흐름, 인물 판정, 추천 알고리즘은 수정하지 않았다. 표지 조판도 기존 `drawCover()`를 사용한다. 새 모듈은 10667바이트의 별도 지연 로딩 청크이며 app-build-manifest의 초기 청크에 없다.

## Astra → Sol 비주얼 고도화

사용자의 모델별 실행 요청에 따라 실제 Astra 에이전트가 대표3인을 구현하고, Sol 에이전트가36인 전수 검수를 수행했다. Astra는 표식색 혼합을 줄여 동일 금속색으로 통일하고, 둥근 부조 경사면·연속 노멀·완만한 볼록면·스튜디오 반사를 적용했다. 아폴론의 월계수 잎도 표지 전용으로 보정했다.

대표3인의 세 마감18장과2D6장을 검수한 뒤 정확한 수치를 `running-card-m2-art-direction-2026-10-10.md`에 기록했다. Sol은 같은 사양으로36인의 WebGL72장과2D72장을 검수했다. 가는 선과 열린 공간을 확대해 확인한 결과 추가 도형 수정이 필요하지 않아 대표 작업의 소스를 보존했다. 자세한 결과는 `running-card-m2-expansion-2026-10-10.md`에 있다.

최종 비주얼 증거는 QA루트의 `astra-heroes/`와 `sol-expanded/`에 있다. 앞 절의 최초 렌더 시간·비교 시트는 초기 M2 기준이며 새 마감의 시간은 해당 최종 report.json을 따른다. 최종 UI PNG와 기준본 비교는 `art-final-ui/`에 보관한다.

최종 실제 UI 검사에서도 설정별 재열기 PNG는 저장본과 바이트 동일했다. 2장 공유, 은·황동 표지만 저장·공유, 추천 링크, 다시 하기와 콘솔 검사도 통과했다. 분석 기준 비교에서 확인된 극소수 픽셀의 차이는 공개 범위 위반이나 눈에 보이는 변경이 아니지만, 최종4장을 모두 바이트 동일하다고 기록하지 않는다. WebGL 색상 반올림 가능성이 있으며 원인을 단정하지 않는다.
