# M2 각면 표지 · 대표 3장

## 확정 근거와 범위

사용자가 직접 제공한 첫 번째 사진의 촘촘하고 화려한 각면 장식과 두 번째 사진의 두꺼운 원판 측면을 결합한다. 앞서 선택한 어두운 금색 바탕·밝은 금속 양각을 유지한다. 사진의 로고나 문양을 복제하지 않고 원형 메달의 환형 장식으로 해석했다.

헤파이스토스·아폴론·제우스 대표 3장 검수 단계다. 표지와 결과 화면에는 메달 하나·표식 하나, 저장 두 번째 장에는 기존 7메달 분석 카드가 나온다. 분석 렌더러·공유 조판·판정 엔진은 수정하지 않았다. 작업 기준 커밋 `13a75dd`, 브랜치 `wt/running-card-single-result`. 운영 배포 전이다.

## 실제 변경

- 표지 전용 `medal-cover-renderer.js`만 변경했다.
- 장식 띠에 4열 × 72개의 금속 피라미드와 바깥쪽 120개 방사형 커팅을 배치했다. 총 408개 돌기·1,632개 삼각형의 실제 기하이며, 면마다 다른 법선으로 빛을 반사한다.
- 중앙 면 반지름 `.855 → .635`, 표식 정규화 `.62 → .76`. 장식 공간을 늘리면서 표식의 물리 크기 감소를 줄였다.
- 원판 뒤 깊이 `-.27`, 전면 외곽 `.112`, 장식 최고점 `.124`. 회전 `(.25,-.34,-.07)`로 두꺼운 측면을 드러냈다.
- 바깥·안쪽 링 반지름 `.983/.93/.651/.638`. 장식 roughness `.32`, flatShading 적용.
- 표식 면의 반사를 보완하는 광원 패널 `[-7,-5,10]`을 추가했다. 어두운 바탕·양각 높이·인물별 내부 홈은 이전 버전을 유지한다.
- WebGL 불가 시 CPU 경로도 같은 삼각형 장식을 그린다. 광학 반사와 측면 표현은 WebGL보다 단순하다.

## 검증 결과

- `npm run build` 성공, `git diff --check` 통과. 기존 img lint·lockfile·Browserslist 경고는 남아 있다.
- 대표 3인 × 금·은·황동 × 피드·스토리 18장, CPU 6장, 결과 화면용 금 메달 정사각형 3장 생성.
- 렌더 경로·표식 존재·인물별 이미지 구별·해제 후 재생성 동일성·콘솔 오류 없음 확인.
- 실제 로컬 UI 7단계 입력부터 결과·저장·다시 시작까지 통과. 모바일 에뮬레이션 390px/375px에서 가로 넘침 없음.
- 피드·스토리 각 2장 생성, 기록 숨김 전환 및 저장 없이 다시 열기 확인. 첫 장은 새 단일 메달, 둘째 장은 분석 카드.
- 피드/스토리의 기록 표시/숨김 및 은/황동 총 6종 분석 PNG가 이전 기준 PNG와 **바이트 단위 동일**하다.
- 공유 API에 전달되는 PNG 파일 2개를 모의 API로 확인했다. 실제 iOS 저장 시트는 이번 검증 범위에 없다.
- 결과 화면의 러닝화 추천 링크 `/recommend` HTTP 200 확인. 전체 사이트의 모든 링크를 검사한 것은 아니다.
