## 소스와 광학 판단

`medal-cover-renderer.js`는 Astra 인계 소스와 바이트 동일하다. SHA-256: `c103600f1634c7a656a78fb5c6f53cdb043ee86a5393ff03ace118eccc1f2465`.

- 전원 longest dimension `.58*S` 유지. 서로 다른 문양을 같은 면적으로 맞추지 않았다.
- 아테나의 올리브 가지와 니케의 종려 잎은 줄기·잎 사이 여백이 390px 피드에서 읽힌다.
- 오르페우스의 네 현은 상단부터 분리되어 보인다. 아래쪽 수렴은 리라의 부착 형태이며, 선을 굵게 하면 이 틈을 줄일 수 있어 유지했다.
- 디오니소스의 솔방울 교차 홈, 벨레로폰의 고삐 구멍, 헥토르의 문·창, 프시케의 날개 구멍 등 음각이 열린 상태로 보인다.
- 아킬레우스의 가는 창과 오리온의 세 별·연결선은 390px에서도 식별된다. 얇은 문양의 실제 부조 면적을 유지했다.
- 긴 인물명(헤파이스토스·펜테실레이아·페이디피데스)과 칭호·문구가 피드/스토리에서 잘리지 않았다.
- 원판 하나·표식 하나, 메달 바깥 인물명/가문/칭호/문구 구성을 유지한다. 표지의 고정 “지난 28일” 이외 개인 기록 숫자는 하네스 입력에 없으며 렌더 인자에도 없다.

커버 전용 광학 수정이 필요한 소실·합침을 발견하지 않아 도상을 추가 수정하지 않았다. `medal3d-character-signs.js`, 분석 렌더, 공유 씬·CSS를 수정하지 않았다.

## 실제 생성과 검증

명령:

```bash
node docs/running-card-harness/cover.mjs /tmp/m2-sol-all-webgl all webgl gold
node docs/running-card-harness/cover.mjs /tmp/m2-sol-all-flat all flat gold
```

| 항목 | WebGL 금 | 2D 대체 금 |
|---|---:|---:|
| 인물 | 36 | 36 |
| 실제 피드 + 스토리 PNG | 72 | 72 |
| 독립 메달 PNG | 36 | 36 |
| 서로 다른 메달 | 36 | 36 |
| 빈/통짜 표식 검사 실패 | 0 | 0 |
| 콘솔 오류 | 0 | 0 |
| 첫 인물 해제 후 재생성 피드/스토리 | 바이트 동일 | 바이트 동일 |
| 생성 중앙값 | 2,187ms | 272.5ms |
| 생성 범위 | 2,131–4,281ms | 238–3,141ms |

시간은 headless Chrome SwiftShader에서 relief·메달·두 카드 합성까지 포함한다. 첫 호출은 폰트 준비 등 초기 비용이 포함되어 실제 기기의 GPU 시간으로 해석하지 않는다. 36명은 각각 렌더러를 생성·해제했고 결정성 재검사는 첫 인물 제우스로 수행했다. 모든 인물을 두 번 렌더한 결과라고 확대 해석하지 않는다.

하네스의 raised ratio는 `.0353088–.2548065`다. 이는 빈/통짜 마스크 감지이며 미적 품질은 실제 접촉 시트에서 별도로 검수했다. 새 테스트 파일은 추가하지 않았다. `npm run build`도 exit 0으로 통과했다. 로그는 QA 루트의 `build.log`에 보존한다.
