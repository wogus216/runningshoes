## 결과

- 헤파이스토스: 망치 머리의 단조 면과 손잡이의 얕은 홈.
- 아폴론: 기존 월계관에 잎맥 부조. 하나의 월계관 표식을 유지.
- 제우스: 독수리의 머리·부리 곡선을 다듬고 날개마다 세 개의 깃 홈, 눈과 꼬리 홈 추가.
- 같은 금속의 무광 바탕과 매끈한 표식 사이 반사 차이를 강화. 금색은 옅은 샴페인 계열로 조정.
- 규칙적인 패턴을 만들던 좌표 해시를 avalanche 해시로 교체하고 표식 위의 거칠기 잡음을 줄였다.
- 주황 리본에 접힘 명암 및 실제 곡면을 적용.

표지 렌더러만 수정했다. `medal3d-character-signs.js`, 공유 조판, 7개 메달 분석 이미지, 판정 엔진은 이번 수정에 포함되지 않는다. 공통 재질 변경은 렌더러를 쓰는 다른 인물에도 적용되므로 Sol 단계에서 나머지 33명의 실제 출력 확인이 필요하다.

## 새 공통 수치

10/10 문서의 수치와 차이가 있으면 **이 문서와 현재 소스**를 따른다.

- 광학 크기 `.58*S`, 1024 마스크, 원판·테두리·카메라 및 mesh 해상도 유지.
- blur 반경 `.006*S`(1024에서 6). 기존 smoothstep 유지. 내부 홈은 검은 구멍이 아닌 회색 높이값으로 새긴다.
- 면 높이: `.025 + .065 * max(0, 1 - 4(u-.5)^2 - 4(v-.5)^2) + relief*.038`.
- 금 재질: `#c2a064 / #f3ddb0 / #725124`, roughness `.43`. 은·황동 기본색은 기존과 동일.
- 표식 roughness: `roughness - height*.21`. 색 혼합 `.035` 유지. 밝은 별도 색으로 칠하지 않는다.
- 거칠기 잡음: `(hash-.5)*8*(1-height*.9)`. 색 잡음: `(hash-.5)*2.5`.
- 환경 바탕 linear RGB `(.13,.125,.115)`.
- 패널 `(w,h,power,position)`: `(5,13,5,[-5,5,10])`, `(2,14,3.4,[9,0,6])`, `(10,2,1.8,[0,-7,10])`, `(6,11,.45,[5,2,16])`.
- 리본 곡면: 16×20 segments, `z=.028*cos(x*pi*.65)+.012*sin(y*2+x)`(정규화 좌표).
- CPU fallback의 노멀도 새 깊이와 볼록면 기울기를 사용한다. 단순한 조명·리본·테두리를 사용하는 대체 렌더로, WebGL과 동일한 금속 반사를 제공하지 않는다.

## Sol이 이어갈 작업

1. 이 버전을 기준으로 36인 전수를 렌더하고 나머지 33개의 가는 선, 열린 틈, 광학 크기를 390px에서 확인한다.
2. 필요하면 표지 전용 `drawSign` 분기에서만 도상을 보정한다. 분석 이미지의 원본 표식은 보존한다.
3. 대표 3장도 포함해 피드·스토리·결과 메달, 금·은·황동, 대체 렌더를 비교한다. 새로운 시안이 검토 중일 때 이전 36인 완료 기록을 새 버전의 검증 근거로 사용하지 않는다.
4. 확장 완료 후 실제 UI에서 첫 장 단일 메달 / 둘째 장 7개 기록 메달 저장 순서와 설정 변경·추천 링크를 확인하고 빌드한다.
