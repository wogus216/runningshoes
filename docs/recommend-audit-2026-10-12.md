# 신발 추천 점검 및 삼국지 기능 제거 — 2026-10-12

## 요청

운영자 요청으로 `/recommend` 삼국지 카드·유형 분류·유형 공유 기능을 제거하고 실제 신발 추천을 점검했다. 기존 러닝카드 기능과 별개인 기능이다.

## 확인한 문제와 수정

1. 트레일 선택에 로드 안정화가 1위로 나왔다. 평발 조건이 안정화를 트레일 카테고리로 취급하고, 로드화 감점만으로는 결과를 막지 못했다. 트레일/로드를 먼저 분리하고 후보가 적어도 다른 노면으로 채우지 않는다.
2. 회복 목적에 상급자·빠른 페이스 가점으로 레이싱화가 올라왔다. 회복 후보에서 레이싱 카테고리를 제외한다.
3. 부상별 TOP 3가 전체 카탈로그를 다시 계산해 예산·발형·다른 부상 조건을 무시했다. 본 추천 후보에서 고르도록 통일했다.
4. 넓은 발에 좁은 일반판만 있는 제품을 감점만 해 추천할 수 있었다. 명시된 발볼 불일치는 제외한다. 입문자 비추천이 정확히 명시된 제품도 입문자 후보에서 제외한다. 설명 중 ‘입문화 중 무거움’처럼 입문자 비추천을 뜻하지 않는 문자열까지 제외하지는 않는다.
5. 한국 정가 미확인 제품이 예산 필터를 통과했다. 유효한 양수 가격이 확인된 제품만 추천한다.
6. caution 평가와 평발 poor 정보가 결과에서 사라졌다. ‘선택 조건에서 확인할 점’에 표시한다. warning은 기존과 같이 해당 부상 조건에서 제외한다. 부상 관련 문구는 데이터의 평가로 표현한다.
7. 평균 비교는 전체 후보 평균인데 화면은 ‘추천 신발 평균’으로 표시했다. 실제 표시 결과의 평균으로 통일하고 가벼운 무게의 차이를 +g로 표시하던 부호 오류를 수정했다. 단일/동점 후보 정규화와 브랜드 다양성 감점 후 음수 표시도 방지한다.
8. 데이터 로딩 실패를 빈 결과로 복원하거나 설문 완료에서 처리하지 못했다. 로딩·재시도·세션 선택지 검증을 추가했다.
9. 여름 데이터 없이 무게만으로 여름 적합성을 단정하는 가점을 제거했다. 화면의 AI 표기는 실제 동작에 맞는 ‘맞춤 러닝화 추천’으로 바꿨다.

## 검증

- 수정 전 재현 테스트: 18개 중 6개 실패. 수정 후 추천 회귀·세션 검증은 모두 통과했다.
- 전체 Vitest: 33개 파일 405개 테스트 통과. 기존 주간 거리·평발·예산·트레일 회귀 검증 포함.
- 동일 3,240개 조합 비교: 트레일에 로드화 노출 4,064건 → 0건, 회복 상위 3개에 레이싱화 노출 112건 → 0건, 넓은 발에 좁은 일반판 노출 566건 → 0건. 건수는 조합마다 나온 결과의 합이며 중복 제품을 포함한다.
- 43,740개 조합(경험·주간 거리·목적·페이스·계절·아치·발볼·예산·대표 부상 조합)에서 예산 초과·용도 누출·선택 부상 warning·잘못된 점수 범위·좁은 일반판 불일치 0건.
- `npm run build` 통과. 다른 페이지의 기존 이미지 권고 경고만 있다.
- 브라우저: 9문항 실제 입력, 부상별 링크의 조건 유지, 주의 표시, 추천 순서, 무게 부호, 320/390px 가로 넘침, 요청 실패/재시도, 세션 복원/초기화/손상 거절 통과. `/tmp/recommend-qa` 산출물. 재현 방법은 `docs/recommend-harness/README.md`.

## 해석 범위

이번 점검은 데이터·설문 조건·출력의 일관성 검증이다. 매칭 점수는 후보 사이의 상대 점수이며 실착 적합 확률이나 의학적 예방 효과가 아니다. 실착과 사용자 만족도를 검증한 것으로 주장하지 않는다. 카테고리·발형·부상 평가는 기존 데이터에 의존한다.
