## 0. 한 줄 요약

**운영자가 GPX를 직접 만들면 코스 지도가 가능하다.** 다만 GPX를 *어떻게* 만드느냐가
합법/위법을 가르고, 만드는 방법에 따라 **정확도 등급을 화면에 표기해야 한다.**

### 1-2. OSM은 쓸 수 있다 (2026-08-23 원문 확인)

- **상업적 사용 허용.** 조건은 `© OpenStreetMap contributors` + copyright 페이지 링크
  ([openstreetmap.org/copyright](https://www.openstreetmap.org/copyright))
- 표시 위치는 지도 모서리. 한 문서에 이미지 여러 개면 **한 번만** 표시
- **feature 100개 미만 정적 이미지는 표시 의무 면제**
  ([OSMF Attribution Guidelines](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines))
- ⚠️ **공식 타일 서버(tile.openstreetmap.org)는 프로덕션 금지.** 정책 원문:
  *"상업 서비스는 언제든 접근이 차단될 수 있음을 특히 인식해야 한다."*
  프리페칭·오프라인 캐싱 금지. 권장 대안 = 상용 제공자 / 자체 호스팅 / 벡터 타일
  ([Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/))

### 1-3. 렌더링 스택

- **MapLibre GL JS** (11.4K stars) — Mapbox 유료화 이후 사실상 표준
- ⚠️ **protomaps.js 는 채택 금지** — README가 *"Maintenance Mode, 신규 기능 없음,
  레거시 Leaflet 전용 권장"* 이라고 명시
- Strava / Garmin / NRC API는 **약관상 불가** (기존 조사, `saturday-crew-page` 메모리)

## 2. GPX 출처별 안전도 — 이게 핵심 판단표

| 만드는 방법 | 안전도 | 조건 |
|---|---|---|
| **직접 달리며 GPS 기록** | ✅ 완전 안전 | 본인이 생성한 사실 데이터. 저작권 문제 없음 |
| **코스 설명(사실)을 읽고 OSM 위에서 도로를 이어 재구성** | ⚠️ 조건부 가능 | 아래 원칙 준수 시. **정확도 '추정' 표기 필수** |
| 대회 공식 GPX 파일 다운로드 | ⚠️ 확인 필요 | 배포 라이선스가 명시된 경우만. 대개 명시 없음 → 기본은 쓰지 않는다 |
| **공식 코스맵 이미지를 깔고 선을 따라 그리기** | ❌ 금지 | 트레이스 = 2차적저작물. §1-1 대법원 2009도291 |
| Strava·Garmin 기록 가져오기 | ❌ 금지 | 약관 위반 (기존 조사) |

### 재구성이 허용되는 이유와 경계

**경로가 지나는 도로는 사실이다.** "여의도공원에서 출발해 한강공원을 따라 반포대교에서
회차한다"는 사실이고, 그 도로들을 OSM 위에서 이어 경로를 만드는 것은 원 지도를
복제하지 않는다.

**경계는 명확하다** — 공식 코스맵 이미지를 배경에 깔고 그 선을 따라 그리면 그건
복제다. 사실(어느 도로를 지나는가)만 취하고, 선은 OSM 도로망에서 새로 잇는다.

## 3. 정확도 표기는 의무다

허구 후기 438건을 걷어내며 세운 원칙을 여기서도 지킨다 —
**추정을 실측처럼 보이게 하지 않는다.**

2026-08-19 조사가 이미 같은 결론을 냈다: *"수치 미공개 대회는 그리지 않는다.
대충 그린 산 모양은 실측처럼 읽힌다."*

화면 표기 규칙:
- `measured` → 표기 없음 (실측이 기본값)
- `official` → "공식 코스 데이터"
- `reconstructed` → **"코스 설명 기반 추정 경로 · 실제와 다를 수 있습니다"** 를
  지도에 붙여 노출. 거리·고도 수치는 **표시하지 않는다**(추정 경로의 거리는 실측이 아니다)

## 4. 데이터 스키마

`src/types/marathon.ts` 의 `CourseInfo` 에 추가:

```ts
export interface CourseGpx {
  /** public/data/gpx/{eventId}.gpx */
  file: string;
  /** 출처 — 화면 표기와 신뢰도를 가른다 (§3) */
  source: 'measured' | 'official' | 'reconstructed';
  /** 확인일 'YYYY-MM-DD' */
  verifiedAt: string;
  /** GPX 에서 계산한 값. reconstructed 면 화면에 노출하지 않는다 */
  distanceKm?: number;
  elevationGainM?: number;
}
```

`CourseInfo` 에 `gpx?: CourseGpx` 추가. 기존 필드는 건드리지 않는다.

## 5. 구현 단계

### 5-1. 파일럿 (대회 1개)
1. `CourseGpx` 타입 추가
2. `public/data/gpx/` 디렉토리 + 대회 1개 GPX 투입
3. GPX 파서 — 거리·고도 계산 (외부 의존 없이 haversine + 고도차 누적)
4. `npm run validate` 에 검사 추가: 파일 존재 · `source` 값 유효 · `reconstructed` 인데
   거리/고도를 화면에 노출하려 하면 에러

### 5-2. 렌더
5. **빌드 타임 정적 이미지 생성** — SSG라 런타임 타일 호출이 0이 된다.
   타일 서버 부하 없고, feature 100개 미만이라 attribution 의무도 면제.
   `scripts/thumbnail/` 의 헤드리스 크롬 파이프라인을 재사용한다
6. 인터랙티브가 필요하면 MapLibre + **상용 타일**(MapTiler/Stadia) 또는 자체 호스팅.
   **공식 OSM 타일 서버 직접 호출 금지** (§1-2)
7. 고도 프로파일 SVG — GPX에 고도가 있을 때만. `source: 'reconstructed'` 면 그리지 않는다

### 5-3. 확산
8. → **§8 확산 인벤토리로 대체**(2026-08-24). 화살표 형식만으로는 착수 판정이 안 된다는 게
   실측으로 드러났다 — 지점 이름이 붙어야 좌표를 찍을 수 있다("녹차밭"·"한강변"은 지점이 아니다)
9. 나머지는 대회 글 쓸 때 함께 채운다 (일괄 작업 금지 — 검증 비용이 크다)

### 8-4. 고도 — SRTM 은 산에서 맞고 도심에서 틀린다

Valhalla `/height`(SRTM 30m)를 참값 아는 지점과 대조:

| 지점 | SRTM | 참값 | 오차 |
|---|---:|---:|---:|
| 설악산 대청봉 | 1692m | 1708m | −16m |
| 남산 정상 | 260m | 262m | −2m |
| 의암호 수면 | 73m | 71.5m | **+2m** |
| 춘천호 수면 | 109m | 103m | **+6m** |
| 대청호 수면 | 72m | 76.5m | **−4m** |
| 여의도공원 | 21m | 8~10m | +12m |
| **한강 수면** | **22m** | **0~5m** | **+18m** |

SRTM 은 DSM(표면 모델)이라 30m 격자에 건물이 섞인다. **산악·호반 ±6m 로 쓸 수 있고,
도심에서만 못 쓴다.** 도심 코스는 애초에 평지라 고도가 의미 없으므로
