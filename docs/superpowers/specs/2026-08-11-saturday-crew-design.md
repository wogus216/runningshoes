## 1. 한 문장 정의

**쎄러데이는 오래된 친구들과 새로 합류한 친구가 함께 벌이는 주말 러닝 도전을, 시즌별 사진과 에피소드로 계속 쌓아가는 공동 앨범이다.**

공식 이름은 **쎄러데이**, 보조 영문 표기는 `SATURDAY RUNNING CREW`다. 이름과 달리 토요일에만 뛰지는 않는다. 이 사실은 첫 화면의 설명이 아니라 앨범 사이에서 발견하는 내부 농담으로 사용한다.

> 쎄러데이
>
> 토요일에만 뛰는 건 아닙니다.

---

## 2. 왜 이 페이지를 만드는가

### 1순위 — 공동 기억

페이지의 첫 고객은 크루 자신들이다. 몇 년 뒤 다시 열었을 때 기록 숫자만이 아니라 그날의 분위기, 사진, 사건, 친구들의 말을 함께 떠올릴 수 있어야 한다.

### 2순위 — 다른 사람의 도전 욕구

외부 방문자가 마지막에 느껴야 할 감정은 다음과 같다.

> 나도 친구들과 이런 도전을 해보고 싶다.

멋진 러너를 구경시키는 페이지보다, 평범한 사람들이 함께 시작하고 실제로 계속해 나가는 모습을 보여주는 페이지를 만든다.

### 3순위 — 인스타그램 연계

각 미션의 사진과 메타데이터를 웹 앨범과 Remotion 릴스가 함께 사용한다. 릴스는 사람을 페이지로 데려오는 예고편이고, 페이지는 오래 남는 원본 앨범이다.

SEO와 수익은 목적이 아니다. 광고 슬롯은 두지 않는다.

---

## 3. 크루와 시즌 1

### 최종 로스터

총 **7명**이며 화면에서 모두 동등한 크루원으로 다룬다.

- 재춘
- 감자
- 형가
- 기태
- 지자
- 남길
- 광묵 — 10K

구성은 **재춘·감자·형가·기태·지자·남길 풀코스 6명 + 광묵 10K 1명**이다. 여섯 명의 중학교 친구와 친구의 형이 함께하지만, 관계를 위계나 특별 게스트 표기로 사용하지 않는다. 실명 대신 위 코드네임을 공개한다.

### 시즌 1의 시작

원래 러닝을 즐기던 친구들이 달리기를 시작하며 우스갯소리로 “우리 다 같이 풀마라톤 한번 해볼까?”라고 말한 것이 실제 접수로 이어졌다.

시즌 표제:

> **웃자고 한 말이 42.195km가 됐다.**
>
> 문제는, 아무도 농담으로 끝내지 않았다는 것.

티저 대표 훅:

> **아무도 진심은 아니었다.**
>
> **접수 전까지는.**

### 시즌 구조

손기정평화마라톤은 페이지의 끝이 아니라 `SEASON 01`이다.

```text
MISSION 00 — 티저와 크루 공개
MISSION 01…N — 공식 크루 러닝과 중요 훈련
RACE DAY — 손기정평화마라톤
MISSION 01 COMPLETE — 기록과 완주 사진
TO BE CONTINUED — 다음 대회 예고
```

다음 대회가 정해지면 `SEASON 02`를 추가한다. 기존 시즌은 수정하거나 덮어쓰지 않고 완성된 앨범으로 보존한다.

## 4. 콘셉트 — 영화처럼 입장하고, 앨범처럼 남는다

### 핵심 톤

첫 10초는 “큰일을 벌이는 팀”처럼 웅장하게 보인다. 읽을수록 현실 친구들의 성격과 내부 농담이 드러난다.

- **입장:** 어두운 미션 화면, 7인 실루엣, 코드네임, D-day
- **멤버 소개:** 히어로 로스터의 문법 + 실제 강점 + 웃긴 약점
- **훈련 기록:** 밝은 스포츠 매거진, 큰 사진, 짧은 캡션
- **퇴장:** 다시 어두워지며 `MISSION COMPLETE → TO BE CONTINUED`

어벤져스는 ‘서로 다른 사람들이 하나의 미션에 모인다’는 구조만 참고한다. 마블 로고, 공식 서체, 캐릭터 이름·얼굴·의상·그래픽은 사용하지 않는다.

### 기존 `Blue Hour / 새벽 소집`에서 바뀐 점

쎄러데이는 실제로 토요일 새벽에만 모이는 팀이 아니다. 모임의 진짜 흐름은 다음과 같다.

```text
단톡방에서 주말 일정 결정
→ 함께 시계를 누르고 출발
→ 러닝 후 식사와 수다
```

따라서 새벽빛이 14주 동안 밝아지는 장치를 전체 콘셉트로 사용하지 않는다. 어두움에서 밝은 앨범으로 바뀌는 전환은 ‘가상의 미션 소개에서 실제 친구들의 기록으로 들어간다’는 의미를 가진다.

### 색과 질감

| 영역 | 방향 | 역할 |
|---|---|---|
| 미션 화면 | near-black navy, 차가운 흰색, signal orange | 영화적 긴장, 숫자와 코드네임 강조 |
| 앨범 | 따뜻한 종이색, 검정 잉크, 제한된 orange | 스포츠 매거진과 오래된 앨범의 중간 |
| 사진 | 과한 필터보다 실제 조명과 입자 유지 | 친구들의 현실감 보존 |
| 퇴장 | near-black navy로 복귀 | 다음 미션의 여운 |

페이지 전체를 둥근 카드 UI로 만들지 않는다. 큰 사진, 단단한 그리드, 비대칭 편집, 큰 숫자와 캡션을 사용한다.

## 5. 공개 전 상태 — MISSION 00

현재 단체사진이 없으므로 첫 공개에서는 **서로 다른 7개의 실루엣**을 사용한다. 실루엣은 실제 인물을 흉내 낸 합성 사진이 아니라, 코드네임이 먼저 등장하도록 만드는 임시 장치다.

첫 공식 훈련에서 단체사진을 촬영하고, 이후 히어로를 실제 단체사진으로 교체한다. 단체사진 촬영은 운영 할 일이지 대표 카피로 내세우지 않는다.

`MISSION 00`의 공개 요소:

- 쎄러데이 워드마크
- 티저 훅 `아무도 진심은 아니었다. 접수 전까지는.`
- 7개 코드네임과 실루엣
- `FULL × 6 · 10K × 1`
- 대회명, 날짜, D-day
- 시즌 표제 `웃자고 한 말이 42.195km가 됐다.`
- 인스타그램 또는 최신 미션으로 가는 CTA

## 6. 정보 구조와 스크롤 동선

첫 공개인 `MISSION 00`은 콘텐츠가 없는 상태에서 문단을 억지로 늘리지 않고 세 개의 강한 장면으로 끝낸다.

```text
1. MISSION HERO
   티저 훅 · 시즌명 · 개인 러너에서 7인 집결로 넘어가는 영상 서사

2. CREW REVEAL
   7개 코드네임 · FULL/10K · 강점과 웃긴 약점 · 동일한 시각적 비중

3. RACE TARGET
   대회명 · 날짜 · D-day · FULL × 6 / 10K × 1
   TO BE CONTINUED · NEXT MISSION · Instagram CTA
```

푸터의 워드마크·Instagram·크레딧은 별도 문단으로 세지 않는다.

첫 공식 러닝 사진이 생기면 네 번째 문단으로 `MISSION LOG`를 추가한다. 이후에는 최신 미션 요약을 상단에 배치하고, 본문은 `MISSION 00`부터 시간순으로 쌓는다. 즉 첫 공개는 3문단 티저지만 데이터 구조는 장기 시즌 아카이브로 확장 가능해야 한다. 정렬 토글은 만들지 않는다.

---

## 7. 멤버 로스터

카드 크기와 시각적 위계는 7명 모두 동일하다. 친구의 형, 풀코스와 10K 여부로 계급을 만들지 않는다.

각 카드의 기본 정보:

```text
코드네임
도전 거리
진짜 강점
웃긴 약점 한 줄
사진 또는 실루엣
선택: 목표 기록, 최근 한마디, 집계 통계
```

예시 데이터는 초기 화면 확인용으로만 사용하고, 공개 전 실제 성격에 맞게 교체한다. 유머는 조롱이나 과장된 가상 캐릭터가 아니라 친구들이 서로 인정할 실제 습관에서 뽑는다.

실명은 기본적으로 공개하지 않는다. 사진 공개 동의는 멤버별로 관리하고, 사진을 원하지 않는 멤버는 계속 실루엣을 사용할 수 있다.

## 8. 미션 앨범

### 무엇을 에피소드로 남기는가

**여럿이 모인 공식 크루 러닝과 중요한 훈련만** 하나의 미션으로 기록한다. 각자의 모든 개인 러닝을 앨범에 올리지 않는다. 개인 러닝은 동의한 집계 숫자만 누적 통계에 반영할 수 있다.

### 한 미션의 구성

1. 스포츠 매거진 표지처럼 큰 대표 사진 1장
2. 미션 번호와 한 줄 제목
3. 날짜 · 코스 · 함께 뛴 거리
4. 현장 사진 5–10장
5. 그날의 사건 또는 멤버 한마디
6. `이번 주의 인물` — 순위가 아닌 유쾌한 회차별 하이라이트
7. 선택: 짧은 영상 클립

예시:

```text
MISSION 03 · 한강 첫 장거리
2026.08.29 · 여의도–반포 · 18km

“출발할 땐 일곱 명, 반환점부터는 각자도생.”

오늘의 사건
물 보급 담당이 가장 먼저 물을 다 마셨다.

이번 주의 인물 · 감자
선정 이유: 코스보다 식사 장소를 먼저 확정함.
```

사진은 대표 사진을 크게 쓰되 나머지도 작은 썸네일로만 소비하지 않는다. 세로·가로 비율을 살린 편집 그리드와 짧은 캡션을 사용한다. 완벽한 러닝 사진뿐 아니라 쉬는 모습, 식사, 흔들린 사진, 실패한 순간도 포함한다.

## 9. 로컬 콘텐츠 운영

사진은 단톡방에 자유롭게 올리고, 운영자가 대표 사진 1장과 스냅 5–10장을 선별해 로컬 미션 폴더에 저장한다.

권장 구조:

```text
content/saturday/
├── season-01.json
└── season-01/
    ├── mission-00/
    │   └── episode.json
    └── mission-01/
        ├── episode.json
        ├── cover.webp
        ├── 01.webp
        ├── 02.webp
        └── clips/
            └── optional-01.mp4
```

`episode.json`은 다음 정보를 가진다.

```ts
interface MissionEpisode {
  id: string;
  season: number;
  number: number;
  date: string;
  title: string;
  course: string;
  distanceKm: number;
  cover: string;
  photos: { src: string; caption?: string }[];
  clips?: { src: string; caption?: string }[];
  quote?: string;
  incident?: string;
  weeklyPerson?: { memberId: string; reason: string };
}
```

JSON을 택하는 이유는 새 의존성이나 Markdown 파서 없이 Next.js와 Remotion이 같은 데이터를 안전하게 읽을 수 있기 때문이다. 긴 글이 필요한 시즌에는 별도 `story.md`를 선택적으로 추가할 수 있다.

사진 추가 후 빌드하면 다음이 자동 갱신되는 것을 목표로 한다.

- 최신 미션 표지
- 시간순 앨범
- 누적 거리와 함께 달린 횟수
- Remotion 주간 릴스 입력 데이터
- 시즌 OG 이미지

데이터베이스, CMS, 로그인, 관리자 화면은 만들지 않는다.

## 10. 인스타그램과 Remotion

### 콘텐츠 체계

- **런칭 티저:** `MISSION 00`, 12–15초
- **정규 시리즈:** 각 미션을 요약하는 20–30초 릴스
- **특집:** 멤버 프로필, D-day, 레이스 데이, 시즌 종료

정규 릴스는 사진만으로도 완성되어야 한다. 짧은 영상 클립이 있는 회차만 오프닝이나 전환에 자연스럽게 섞는다. 영상 촬영을 매주 숙제로 만들지 않는다.

### MISSION 00 티저 초안

```text
0–2초   검은 화면, 짧은 신호음
        아무도 진심은 아니었다.

2–4초   접수 완료를 암시하는 숫자/라인
        접수 전까지는.

4–8초   재춘 · 감자 · 형가 · 기태 · 지자 · 남길 · 광묵
        7개 코드네임이 차례로 점등

8–11초  FULL × 6 · 10K × 1 · 2026.11.15

11–13초 웃자고 한 말이 42.195km가 됐다.

13–15초 쎄러데이 · MISSION 00
        사이트 주소
```

실제 단톡방 캡처는 사용하지 않는다. 개인정보를 노출하지 않고, 실제 대화를 과도하게 연출해 설명하지 않기 위해서다.

### 정규 릴스 구조

```text
미션 번호와 대표 사진
→ 날짜·코스·거리
→ 사진 6–10장의 매거진형 전개
→ 그날의 사건 또는 한마디
→ 다음 미션/D-day
→ 사이트 주소
```

페이지와 릴스의 폰트·색·미션 번호 체계는 동일하게 유지한다.

## 11. 기술·성능·접근성 원칙

- Next.js App Router의 `(challenge)` 라우트 그룹을 유지한다
- 모바일 390px과 인스타그램 인앱 브라우저를 우선한다
- 웹 앨범은 서버 컴포넌트와 SSG를 기본으로 한다
- 시네마틱 모션은 히어로와 섹션 전환에 집중한다
- `transform`과 `opacity` 위주로 애니메이션한다
- `prefers-reduced-motion`에서 핵심 정보가 사라지지 않는다
- 사진은 `next/image`, 명시적 크기, 반응형 `sizes`를 사용한다
- 첫 화면 대표 이미지를 제외한 앨범 이미지는 지연 로딩한다
- 터치 타겟은 최소 44px을 유지한다
- 실루엣과 그래픽은 자체 SVG/CSS로 제작한다
- 마블 IP 자산을 사용하지 않는다
- GPS 원본, 건강 정보, 개인 활동 내보내기 파일을 공개 저장소에 커밋하지 않는다

## 12. 참고 방향

한 사이트의 표면을 복사하지 않고 역할별로 나눠 참고한다.

| 역할 | 참고 대상 | 가져올 것 | 가져오지 않을 것 |
|---|---|---|---|

## 13. 만들지 않는 것

- 멤버 순위와 MVP 경쟁
- 개인별 상세 URL
- 댓글, 좋아요, 응원 메시지 입력
- 실시간 Strava/Garmin/NRC 연동
- 모든 개인 러닝의 상세 로그
- 친구들의 사진 업로드 관리자 화면
- 실제 단톡방 캡처 공개
- 단체사진이 없다는 사실을 대표 훅으로 사용
- 첫 화면부터 끝까지 이어지는 마블풍 UI
- 페이지 안의 광고

## 15. 출시 전 필요한 실제 자료

1. 첫 공식 훈련에서 찍은 가로형 단체사진 1장
2. 멤버별 `진짜 강점`과 `웃긴 약점` 각 한 줄
3. 광묵의 공개 거리 표기 `10K` 최종 확인 완료
4. 인스타그램 핸들과 사이트에 노출할 계정 링크
5. `MISSION 01` 대표 사진 1장과 스냅 5–10장

자료가 없어도 `MISSION 00`은 공개할 수 있다. 단, 공개 전 코드네임과 종목 수는 반드시 실제 상태와 일치시킨다.
