# 첫 30km — 기획 브리프

작성: 2026-09-11. 상태: 미디어 수령 및 로컬 시제품 구현, 브라우저 검증 진행 중.
사용자의 2026-09-11 답변을 기준으로 한다. 아래 연출·문구는 별도 표시한 제안이며 실제 사건으로 취급하지 않는다.

## 목적과 확정된 이야기

- 사용자의 인생 첫 30km 완주를 개인 기록으로 남긴다. 크루 전체의 첫 30km라고 표현하지 않는다.
- 마라톤 준비를 위한 러닝. 원래 목표는 25km였다.
- 코스: 신대방역 출발 → 마곡나루 → 돌아오기. 정확한 이동 경로는 아직 확인되지 않았다.
- 동행: 형묵. 페이스메이커 역할이며, 28km에서 포기하지 않고 이어가는 데 도움을 주었다.
- 출발 전에는 특별한 생각이 없었고, 러닝 내내 즐거웠다.
- 약 23km부터 힘들어졌다. 사용자가 반복한 말: “이정도 고통 아무것도 아니다 즐거운 거다”.
- 완주 직후 반응: 해냈다는 것이 신기했다.
- 남기고 싶은 풍경: 한강(사용자가 후보로 언급).
- 핵심 기록: 거리와 첫 30km. 영상에서 확인한 실제 거리 30.02km, 날짜 2026-09-05, 시작 07:29. 완주 시간은 필수 강조 항목이 아니다.

## 관객과 선호

- 친구·지인·일반 방문자에게 공유한다.
- 남길 감정: “좋은 추억을 남겼네”. 다음 메시지: “준비는 계속된다”.
- 거칠고 에너지 넘치는 분위기, 감동과 여운은 가능. 과도한 신파와 거창한 영웅 서사는 피한다.
- 사용자 레퍼런스: 록키의 박물관 앞 주먹을 올리는 장면, 애플 웹사이트 컨셉.
- 디자인 해석 제안: 록키에서 신체적 에너지와 도달의 기쁨을, 애플에서 화면 집중도와 스크롤 전환의 정교함을 가져온다. 특정 웹페이지는 아직 지정되지 않았다.
- 검은색 중심 배경. 음악 사용 희망 없음. 무음으로 완결되는 경험을 설계한다.
- 엔딩: 이름이 위로 올라가는 영화 크레딧과 강한 여운.
- 마지막 문장은 사용자 원문 유지: “이제 러닝의 계절이 왔다”.

## 크레딧에 포함할 내용

- 형묵 — 페이스메이커.
- 스포식스 — 에너지젤. 브랜드 표기는 포장 또는 사용자 확인 후 확정.
- 게토레이 — 음료.
- 기타 실제 사 먹은 음식은 자료 수령 후 추가.
- 구매한 보급품을 공식 후원사로 표현하지 않는다. 제안 역할명: 에너지 보급 / 수분 보급.
- 크레딧 이름은 제공 영상에 표시된 권재현으로 적용했다. 사용자에게 이 표기를 알렸다. 검은 민소매·검은 모자·주황 선글라스의 러너를 본인으로 이해했다고 알렸으며, 개별 사진에 인물 이름을 단정하는 캡션은 사용하지 않았다.
- 공개 제외 대상으로 지정한 이름·얼굴·장소·대화는 현재 없음.

## 범위와 일정

- 쎄러데이 사이트 안의 별도 페이지. 로컬 시제품 경로: /saturday/first-30k.
- 모바일 우선, 데스크톱 대응.
- 공개 희망: 2026-09-13 일요일로 사용자 확정. 실제 러닝 날짜는 2026-09-05. 공개 예약이나 배포는 아직 수행하지 않았다.
- 무료 자료 우선. 사용자 지정 Downloads/쎄러데이/30 폴더에서 JPG 15장(러닝 사진 14장, 음료 제품 이미지 1장), MP4 1개(21.4187초, 592×1280)를 수령했다. 별도 기록 캡처는 없으며 영상 마지막에서 30.02km를 확인했다.
- GPS 경로는 영상으로 보유한다고 함. GPX 파일 보유는 확인되지 않았다.
- 기존 오이도 route.mp4는 다른 러닝의 자료이므로 이번 코스로 재사용하지 않는다.
- 사용자는 다양한 3D 웹 기능을 경험하고, 제작 과정을 저장하고 재사용 가능한 스킬로 내재화하길 원한다.

추천: A. 원래 25km 목표였다는 사실을 중심에 두면 개인적인 이야기가 명확해진다. B의 한강 사진, C의 보급품을 A의 장면 재료로 활용하되 탐색 방식은 하나로 유지한다.

## 추천안 장면 구성 — 문구와 연출 초안

1. 오프닝: 검은 공간의 입체 숫자 25. 문구 제안 “원래는 25km만 뛸 생각이었다.”
2. 출발과 한강: 신대방역 → 마곡나루 → 돌아오기. 실제 사진을 서로 다른 깊이에 놓고 스크롤로 통과. 정확한 GPS 지도처럼 표현하지 않는다.
3. 23km: 화면 변화의 간격을 좁히고 구도를 조여 어려워진 순간을 표현. 심한 흔들림·점멸 없이 사용자의 말을 개인 회고로 보여준다.
4. 25km: 원래 목표를 통과하는 문턱. “25에서 멈추기로 약속했다” 등의 미확인 사건은 추가하지 않는다.
5. 28km: 형묵의 사진 또는 함께 찍은 사진에 집중. 문구 제안 “28km. 형묵이 덕분에 계속 갔다.” 형묵의 대사를 창작하지 않는다.
6. 30km: 카메라를 넓혀 실제 완주 사진과 첫 30km 타이틀 공개. 실측 거리는 기록 확인 후 별도로 정확하게 표기.
7. 크레딧: 주인공, 형묵, 에너지젤, 게토레이, 확인된 음식. 약 20~30초 길이의 자동 스크롤 제안. 재생·일시정지·마지막 문장으로 건너뛰기 지원.
8. 마지막: “이제 러닝의 계절이 왔다”. 보조 문구 제안 “준비는 계속된다.” 다시 보기 및 기존 쎄러데이 이동.

권장 전체 체험 분량: 약 90~120초. 본문은 사용자가 스크롤 속도를 결정하므로 강제로 시간을 맞추지 않는다.

## 3D 제작과 검증 계획

- 학습 목표를 반영해 실제 WebGL 3D 장면을 사용하는 방향을 우선 검토한다. CSS 원근 효과만으로 완료했다고 표현하지 않는다.
- 하나의 3D 무대에 카메라 이동, 입체 타이포그래피, 깊이별 사진, 조명 전환을 구성한다. 기술 선택과 신규 의존성은 구현 때 확인한다.
- 텍스트와 크레딧은 읽고 조작할 수 있는 HTML로 제공한다.
- 모바일 입력은 스크롤·탭 중심. 마우스 호버나 기기 기울이기를 필수 조작으로 두지 않는다.
- 처음에는 25 → 30 → 크레딧 전환의 짧은 시제품으로 화면 집중도·리듬·모바일 부드러움을 검증한다.
- 사진 수령 후 해상도·구도·실제 순간을 분류하고 장면과 대응시킨다. 거리별 촬영 위치를 임의로 단정하지 않는다.
- 모션 감소 설정과 WebGL 불가 환경에서도 사진과 이야기를 볼 수 있는 정적 대안을 준비한다.
- 구현 완료 조건: 모바일·데스크톱 확인, 크레딧 제어 확인, 미디어 누락·문자 잘림 확인, npm run build 통과.
- 기능 확장은 핵심 경험 검증 후 진행한다. 무관한 페이지·다른 진행 중 변경은 수정하지 않는다.

## 재사용할 스킬로 정리할 범위

- 우선 이 브리프와 결정·시제품 검증 결과를 문서로 남긴다.
- 실제 구현·검증 후 skill-creator 지침을 읽고 스킬을 작성한다. 검증 전 제작법을 성공 사례로 기록하지 않는다.
- 담을 항목: 인터뷰 → 사실 정리 → 미디어 분류 → 장면 설계 → 3D와 HTML 구성 → 모바일 최적화 → 크레딧 제어 → 품질 확인.
- 30km의 고유 내용은 프로젝트 데이터에 남기고, 스킬은 다음 러닝 기록에도 적용 가능한 절차로 만든다.

## 다음 입력

- 로컬 시제품을 보고 화면·사진·문구 취향 피드백.

현재 완료 범위: 기획 브리프, 실제 사진 15장 웹용 사본 및 영상 최적화, WebGL 3D 본편·기록 영상·사진첩·크레딧 로컬 구현. 초기 빌드 통과 후 시각 수정과 최종 검증 진행 중. 배포는 미실행.
