### 링크 보존 — 첫 시도에서 20개가 사라졌다

펼친 밴드가 `slice(0, shown)`으로 12행만 렌더해 **정적 HTML 링크가 80/100**이었다.
잘라내는 대신 전부 렌더하고 초과분에 `hidden`을 걸어 해결했다(`marathon-row.tsx`의 `folded`).
`.row`가 `display: grid`라 `hidden` 속성의 기본 `display:none`을 덮어써서
`.row[hidden] { display: none; }`을 CSS에 명시해야 했다.

검증 스니펫:

```bash
grep -o 'href="/marathon/[^"]*"' out/marathon.html | sort -u | wc -l   # 100
grep -o 'hidden=""' out/marathon.html | wc -l                          # 21 (숨김 행)
```

### 모바일에서 글자가 포개졌다

`.region`과 `.dist`를 같은 `grid-area: meta`에 두고 `display: inline`으로 나란히 놓으려 했으나,
**grid item은 `display: inline`을 무시하고**(blockification) 둘 다 그 영역 전체를 차지해
"서울"과 "10K"가 겹쳐 렌더됐다. 각자 셀(`'region dist'`)로 분리해 해결.

### `DISTANCE` 라벨이 잘렸다

`.chipLabel { width: 46px }`에 8글자가 안 들어가 `DISTANC`로 보였다 → 62px.
`scrollWidth > clientWidth` 로 잘림을 판정한다:

```js
[...document.querySelectorAll('[class*="chipLabel"]')]
  .map(l => ({ text: l.textContent, clipped: l.scrollWidth > l.clientWidth + 1 }))
```

### `lastVerified` 조건부 표기

데이터에 아직 `lastVerified`가 한 건도 없어 화면에는 안 나온다(의도 — 확인하지 않은 것을
확인한 것처럼 보이게 하지 않는다). **렌더된 적 없는 코드는 검증된 게 아니므로** 임시 주입으로 확인했다:

| 대회 | `lastVerified` | `확인 · 신청 전` 매칭 |
|---|---|---|
| 춘천마라톤 (임시 주입) | `2026-07-28` | 2 ✅ |
| 안동마라톤 (미보유) | 없음 | **0** ✅ |

주입 데이터는 원복했다. `grep`으로 확인할 때 React가 JSX 표현식 경계에 `<!-- -->`를 넣으므로
`2026.07.28 확인`은 안 잡히고 `확인 · 신청 전`으로 찾아야 한다.
