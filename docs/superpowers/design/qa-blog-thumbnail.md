## 0. 측정 방법

좌표 실측은 Chrome DevTools MCP(`evaluate_script`)로 실행했다. 사용한 스니펫은 스펙 §6·브리프
그대로다:

```js
// 잘림률 — naturalRatio == boxRatio 이면 잘림 없음
const crop = (sel) => [...document.querySelectorAll(sel)].slice(0, 6).map(i => {
  const b = i.getBoundingClientRect();
  return {
    src: i.currentSrc?.split('/').pop()?.slice(0, 36),
    natural: +(i.naturalWidth / i.naturalHeight).toFixed(3),
    box: +(b.width / b.height).toFixed(3),
    cropPct: +(((i.naturalWidth / i.naturalHeight) / (b.width / b.height) - 1) * 100).toFixed(1),
  };
});
```

```js
// 가로 스크롤
({ scrollW: document.documentElement.scrollWidth,
   clientW: document.documentElement.clientWidth,
   horizScroll: document.documentElement.scrollWidth > document.documentElement.clientWidth })
```

**운영상 주의 — 브라우저를 다른 에이전트와 공유한다**: 이 세션은 다른 팀 에이전트들과 같은
Chrome MCP 인스턴스를 쓴다. 1440 → 390 전환 도중 "현재 선택된 페이지"가 다른 에이전트의
탐색으로 `asics.co.kr`로 바뀌어 있던 것을 `evaluate_script`의 `location.href` 확인으로
잡아냈다. 이후 모든 측정은 `isolatedContext: "t5-impl-qa"`로 만든 전용 탭에서, **매 스크립트
실행 전 `location.href`로 페이지 신원을 확인**하는 방식으로 재측정했다. 아래 수치는 전부
신원 확인이 통과한 실행 결과다.

## 이 작업 중 발견해 별도로 정정한 것 — 카야노 33 가격

Task 3B의 데이터 줄 작업에서 **블로그 본문과 신발 DB의 카야노 33 가격이 어긋나는 것**을
발견했다(본문 209,000원 vs DB 199,000원). 운영자가 **199,000원**을 확인해 DB가 맞았고,
블로그 쪽 **5곳**을 정정했다(커밋 `dfc2be3`, `9aed20c`).

| 글 | 잘못된 표기 | 정정 |
|---|---|---|
| 카야노 33 리뷰 (`2026-06`) | "한국 공식가 **209,000원**" | 199,000원 |
| 가을 마라톤 비교표 (`2026-05`) | Kayano 33 행 209,000원 | 199,000원 |
| **32 vs 33 비교** (`2026-05`) | "209,000원 **추정**" · 차이 "**+10,000원**" | 199,000원 · **동일** |
| 33 출시 예고 (`2026-05`) | "정가(예상) 199,000~209,000원" | "정가 199,000원 (32와 동일)" |
| 3파전 비교 (`2026-06`) | 카야노 열 209,000 | 199,000 |

**원인**: 출시 **전**에 쓴 "209,000원 추정"이 출시 후 실제가로 갱신되지 않은 채 다른 글로
복사되며 번졌다. 32 vs 33 비교글이 가장 나빴다 — "33이 32보다 1만원 비싸다"고 표로 단정하고
있었고, 그 글은 CTR이 높은 vs 비교 유형이다(GSC `젤카야노 32 33 차이` 순위 4.2 · CTR 15.8%).

**아직 남은 것**: 32 vs 33 글의 "세일가(전망)" 행이 33을 `190,000원 (출시 직후 풀가)`로
적는다. 정가가 199,000원이므로 "풀가 190,000원"은 어긋나지만, 이건 시세 전망이라 실제
유통가를 모르는 채 고치면 또 다른 추측이 된다 — 손대지 않았다.

**후속 후보**: 같은 경로로 들어간 가격 오류가 다른 신발에도 있을 수 있다.
블로그 본문의 가격 표기와 신발 DB `price`를 일괄 대조해볼 만하다(이번 범위 밖, 미실행).
