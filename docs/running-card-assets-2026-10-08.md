# 러닝카드 표식 제거 이미지 연결 — 2026-10-08

운영자 요청으로 표식 제거 PNG 14장을 WebP로 변환하고 기존 러닝카드 기능에 연결했다. 기존 22장과 합쳐 36명 모두 인물 이미지를 사용한다. `/running-card`는 기존 설정대로 noindex이며 메뉴·사이트맵에는 노출하지 않는다.

## 이미지 처리

Desktop `러닝카드-표식지우기/완성`의 PNG를 사용했다. 원본 입력은 보존했다. 원본 해상도 확대 검수 후 아탈란타·벨레로폰·헤파이스토스의 신발 세부 표식을 추가 수정했다. 출력은 720×1279, WebP quality 75 / effort 6이며 imageFocus는 머리 중심의 수동 측정값(오차 약 ±0.03)이다. 생성 출처·해시·용량은 `public/images/running-card/IMAGE_CREDITS.md`에 기록했다.

## 검증

- Vitest: 33개 파일, 472개 테스트 통과.
- 정적 빌드 통과. 데이터 검증 오류 0개(기존 경고 9개), lint 오류 0개(기존 경고 4개).
- Chrome CDP에서 실제 입력 → 결과 → 공유 버튼으로 피드/스토리·메달 표시/숨김 조합의 PNG 8장 저장, JavaScript 오류 0개.
- 공유 링크 14개에서 해당 인물 WebP 로딩·크기·이름·AI 생성 표기 확인, JavaScript 오류 0개.
- 추가 14명 × 피드/스토리 표지 28장의 머리 크롭 확인. 이 전수 크롭 점검은 메달 콜백을 생략한 캔버스 렌더이며, 메달 포함 실제 저장 동작은 위 사용자 흐름으로 별도 확인했다.

## 범위와 남은 출시 점검

이번 배포는 기존 비공개 주소의 기능과 이미지 연결이다. 실기기에서 인스타 업로드 후 가림·압축, 광고 겹침, 디자인 승인과 기존 22장 원본 전수 검수는 이 작업에서 수행하지 않았다. 스토리의 고정 상단 제목과 인물의 겹침은 기존 레이아웃을 유지했다. 정식 메뉴 공개 전에 기존 S5 보고서의 출시 점검을 별도로 진행한다.
