# Bing SEO 분석 대조 및 수정 (2026-10-13)

Bing CSV는 ALT 64페이지, 짧은 설명 92페이지, 긴 제목 45페이지, IndexNow 미채택,
인바운드 링크 관련 사이트 경고 1건을 담았다. URL·수집일·판정 기준은 없다.
페이지 수는 중복될 수 있으므로 합산하지 않는다.

운영 HTML 7페이지와 10/10 로컬 빌드 HTML 1,073페이지에서 ALT 속성 누락은 0건이다.
빈 ALT는 존재한다. 장식 이미지와 같은 링크 안의 텍스트를 반복하는 이미지는 빈 ALT가
의도될 수 있어 일괄 채우지 않는다. Bing 상세 URL이 필요하며 ALT 64건 해결로 보고하지 않는다.
인바운드 링크도 대상 도메인과 상세 사유 없이 유해 링크로 단정하지 않는다.

  긴 소개만 완결된 첫 문장 또는 단어 경계에서 줄인다. 카야노 33의 `· 무게 2` 절단을 해소한다.
- `/blog`, `/compare`, `/recommend` 설명에 해당 페이지의 실제 탐색·비교 기능을 보강한다.

## IndexNow 운영

`.github/workflows/indexnow.yml`은 Cloudflare의 `Workers Builds: runningshoes` 체크가
성공한 후 main 계열 커밋을 checkout해 `npm run indexnow`를 실행한다. 최초 실행은 직전 커밋,
이후에는 Actions cache에 보관한 마지막 성공 SHA와 비교한다. 캐시가 없으면 직전 커밋을 기준으로 한다.

월별 블로그·마라톤 및 개별 신발 데이터는 TypeScript 객체 단위로 비교한다.
추가·변경·삭제된 상세 URL과 해당 목록을 후보로 삼으며, 페이지·레이아웃과 공유 신발 설명
변경은 관련 라우트를 통지한다. 공개 sitemap에 없는 새 URL(noindex)은 제외하며 삭제 URL은 통지한다.
템플릿 변경 첫 실행은 관련 경로 전체가 대상으로 잡힐 수 있다.

운영 키가 배포되어 일치하는지 확인한 뒤 IndexNow API로 최대 10,000 URL씩 전송한다.
HTTP 200은 수신 성공, 202는 수신 후 키 검증 대기다. 두 응답 모두 색인·순위 보장이 아니다.
실패한 제출은 성공 SHA를 갱신하지 않는다.

- 수동 재실행: GitHub Actions → IndexNow after deployment → Run workflow (main)
- 조회만: `npm run indexnow -- --dry-run --base=<기준 SHA>`
- 테스트: `npm run test:indexnow`
- 다른 위치의 공유 컴포넌트·데이터 변경을 모두 자동 추론하는 기능은 없다. 이 경우 관련 URL의
  경로 템플릿 변경 범위 또는 별도 제출 대상을 점검한다.

참고: https://www.indexnow.org/documentation · https://developers.google.com/search/docs/appearance/title-link
