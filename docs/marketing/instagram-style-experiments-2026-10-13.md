# ALLRUNABOUT 인스타 운영 — 하루 2~3개로 인기 패턴 찾기

작성: 2026-10-13. 기존 ‘러닝카드 중심 주 2개’ 계획을 대체한다. 상태: 실행 설계·AI 서브에이전트 검토 완료, 제작·발행·계정 조작은 미실행.

## 사용자 의도와 조건

러닝카드는 계정을 시작하는 첫 소재다. 장기적으로 러닝화·러닝 기록·러너 생활 정보를 여러 스타일로 게시하고 반응이 좋은 조합을 찾아 키운다. 광고비 0원, 주 4~6시간, 크루 단톡방 제외. 계정 상태는 미확인으로 신규 계정을 가정한다.

하루 2~3개가 스토리를 포함하는지 아직 답변이 없어 피드/릴스 본게시물 하루 2개를 기본으로 설계했다. 스토리는 별도 재활용이다. 하루 세 번째 본게시물은 제작 여력 확인 후 일부 날부터 확장한다. 스토리 포함 수량이라면 하루 본게시물 1~2개와 스토리로 조정하고 피드 실험 반복수는 별도로 센다.

## 1. 운영 원칙

- 기본은 하루 2개, 주 14개. 첫 달 기본 56개. 하루 3개를 매일 하면 주 21개/4주 84개로 제작량이 50% 늘어난다.
- 다양성은 유지한다. 새로운 주제·스타일을 시험하되 게시물마다 재조사·새 디자인을 시작하지 않는다.
- 콘텐츠 단위는 검증된 원자료에서 독자가 가져갈 사실·판단·질문 하나를 뽑은 짧은 게시물이다.
- AI 초안과 템플릿을 묶어 제작하고 운영자는 사실·가독성·목표 행동을 검수한다.
- 조회수가 큰 게시물, 팔로우를 만드는 게시물, 사이트 방문을 만드는 게시물의 역할을 구분한다.
- 기존 사이트의 검증된 글·신발 자료를 재구성한다. 새 가격·출시 일정은 현재 공식 자료로 재확인한다. 새 의료 주장이나 추측 수치는 빈도를 채우기 위해 만들지 않는다.

## 2. 주제와 스타일을 따로 기록

첫 두 주 비교 주제는 두 묶음으로 제한한다.

- T1 러닝화 선택: 용도, 발 맞음, 비교 기준, 가격 대비 선택 등.
- T2 러닝 기록·러너 생활: 기록 이해, 목표, 꾸준함, 공감 상황 등. 러닝카드는 첫 소개 소재이며 모든 게시물의 목적지가 되지 않는다.

주간 편성 참고안은 러닝화 6개 / 기록 정보 4개 / 공감·참여 2개 / 자유 소개 2개다. 첫 주 자유 소개는 러닝카드, 다음 주부터 브랜드·새 소재·간단한 릴스로 전환한다. 콘텐츠 비율은 결과를 보고 바꾼다.

3가지 반복 스타일:

| 스타일 | 실제 모습 | 바꿀 요소 | 유지할 요소 |
|---|---|---|---|
| A 이미지 중심 잡지 | 신발·메달 사진 크게, 짧은 제목, 설명 한 줄 | 사진 배치, 색 분위기, 제목 표현 | 계정 서명, 출처, 모바일 가독성 |
| B 큰 글자 포스터 | 굵은 한 문장, 강조 단어, 근거 한 줄 | 문장 리듬, 배경색, 강조 위치 | 계정 서명, 출처, 모바일 가독성 |
| C 설명 노트 | 체크·간단한 표·도식으로 선택 기준 하나 설명 | 표/도식, 글과 그림 비율 | 계정 서명, 출처, 모바일 가독성 |

A를 신발에만, B를 러닝카드에만 쓰지 않는다. 두 주제 모두 세 스타일을 적용한다. 비슷한 내용의 색깔만 바꾼 연속 재게시가 아니라 각 게시물에 독립적인 정보나 질문이 있어야 한다.

첫 비교 24개는 같은 단일 이미지 형식을 기본으로 한다. 자유 슬롯 4개에서 캐러셀/릴스를 탐색한다. 이후 반응이 좋은 주제·표현은 여러 장 설명과 릴스로 확장한다. 서로 다른 형식의 조회수를 스타일의 승패로 직접 비교하지 않는다.

각 원자료에서 서로 다른 항목을 선택한다. 같은 주제 묶음도 세부 소재 강도가 다르므로 이 비교는 완전한 인과 검증이 아니다. 제목과 자료 ID를 남기고 좋은 조합을 다른 소재에서도 반복해 본다.

## 4. 3~4주차 — 좋은 조합을 확대

두 주가 끝났다고 한 스타일을 완전히 버리지 않는다. 먼저 같은 주제·형식 안에서 도달, 저장, 공유가 반복해서 상대적으로 좋았던 후보를 찾는다.

다음 두 주 28개 편성안:
- 14개: 반응이 좋았던 스타일·주제 조합을 새로운 소재에 적용.
- 8개: 다른 기존 스타일을 계속 비교.
- 6개: 새로운 스타일·후크·형식 중 하나를 시험.

50/30/20에 가까운 이 비중은 운영 가설이다. 모든 스타일의 도달이 너무 작거나 결과가 들쭉날쭉하면 확대를 보류하고 균형 편성을 이어간다. 한 번 크게 조회된 게시물만으로 승자를 결정하지 않는다.

세 번째 본게시물 추가는 주 14개 제작을 실제로 2주 유지하고, 사실 검수 누락 없이, 운영 시간이 6시간 안에 들어왔을 때 선택한다. 먼저 주 2~3일만 추가하고 시간을 확인한다. 매일 3개로 확장하려면 21개 제작 시간을 다시 계산한다. 게시물 수가 늘면 도달이 자동으로 늘어난다고 가정하지 않는다.

## 5. 제작 방식과 시간 예산

처음에는 세 템플릿과 기록표를 만드는 준비 시간이 필요하다. 첫 4개를 실제 제작해 시간을 재고 주 14개 예산을 조정한다. 아직 자동 생성·예약발행 시스템은 구현하지 않았다.

아래는 검증된 원자료가 있고 짧은 이미지 게시물이 중심이라는 가정의 목표 예산이다.

| 작업 | 주간 목표 시간 |
|---|---:|
| 사이트에서 원자료·세부 소재 선정 | 30분 |
| 원자료의 현재 정보 확인 | 45분 |
| AI 초안 생성·문장 수정 | 70분 |
| 템플릿에 배치·이미지 출력 | 42분 |
| 업로드·예약·링크 확인 | 28분 |
| 댓글·메시지 답변 | 30분 |
| 지표 기록·다음 주 편성 | 20분 |
| 수정·여유 | 60분 |
| 합계 | 325분, 약 5시간 25분 |

초보자의 첫 제작과 복잡한 영상에는 이 속도를 보장할 수 없다. 사이트 기능 개발·새 템플릿 제작은 이 반복 운영 예산에 포함하지 않는다.

시간을 넘으면 영상 편집, 캐러셀 장수, 새 조사 범위, 매번 새 디자인부터 줄여 일일 빈도를 유지한다. 그래도 사실 검수 시간이 확보되지 않으면 수량을 조정한다.

발행 전에 확인할 네 가지:
1. 독자가 가져갈 정보·판단·질문이 하나 있는가?
2. 수치·가격·제품 설명이 원자료와 맞는가?
3. 휴대전화에서 읽히고 오해할 표현이 없는가?
4. 최근 내용과 같은 재탕이 아니며 요청하는 행동은 하나인가?

## 6. 초보용 성과 확인

게시물마다 목표를 하나 적는다: 도달 / 저장·공유 / 팔로우 / 사이트 방문.

- 도달: 처음 보는 사람이 얼마나 봤는지 관찰.
- 저장·공유: 다시 보고 싶거나 다른 사람에게 보내고 싶은 콘텐츠인지 관찰.
- 팔로우: 계정을 계속 볼 이유가 있는지 관찰. 게시물별 지표가 앱에 없으면 계정 전체 증가만 기록.
- 사이트 방문: 프로필·스토리에서 사이트로 들어오는 세션과 실제 러닝카드 사용을 관찰.

관찰 시점은 이번 운영 규칙이다.
- 약 24시간: 오탈자·불편·초기 댓글만 확인. 모든 숫자를 세 번씩 적지 않는다.
- 약 72시간: 핵심 도달·저장·공유 수치를 기록. 매일 고정 점검 때 해당 게시물을 확인하고 실제 경과 시간을 남긴다.
- 7일: 좋은 후보와 같은 주제의 비교 게시물만 재확인.

같은 게시 후 경과 시간끼리 비교하고, 앱에 없는 지표는 0이 아니라 N/A로 기록한다. 평균 시청시간/영상길이는 완주율이 아니다. 저장÷도달과 공유÷도달은 행동 횟수 비율이며 원래 건수를 함께 남긴다. 도달 10명 중 공유 1회와 도달 1,000명 중 공유 50회를 비율 하나로 승패 판단하지 않는다.

두 주 비교에서는 스타일별 중앙값(숫자를 순서대로 놓았을 때 가운데 값)을 참고하고 주제별 결과도 확인한다. 작은 표본·날짜·세부 주제 차이가 있으므로 ‘유력 후보’로만 표시한다.

게시물표의 도달을 합쳐 계정의 고유 도달로 사용하지 않는다. 주간 계정표는 팔로워 순증·계정 도달·프로필 방문·외부 링크 클릭(제공될 때)·GA 인스타 유입·전체 제작 시간만 기록한다.

프로필 공통 UTM은 인스타 전체 웹 유입용이다. 특정 피드 게시물의 사이트 전환이나 매출로 확정 귀속하지 않는다. 상세 UTM·러닝카드 이벤트 한계는 기존 문서의 측정 설명을 참고하되 이전 발행 일정은 사용하지 않는다.

## 7. 서브에이전트 검증

세 AI 역할로 새 방향을 다시 검토했다. 사람 전문가 검증으로 표시하지 않는다.

- 마케팅 전략: 러닝카드는 첫 소재로 두고 러닝화·기록·공감으로 확장. 매번 새 디자인 대신 3스타일 반복 제작.
- 실행 비판: 하루 2개를 유지하려면 자료 재구성과 배치 제작이 필요. 첫 4개로 제작 시간을 실측. 주 21개는 조건부 확장.
- 측정 검토: 같은 형식·주제·경과 시간 안에서 비교. 24개 반복 실험과 4개 자유 게시를 분리. 작은 표본은 탐색 결과.
