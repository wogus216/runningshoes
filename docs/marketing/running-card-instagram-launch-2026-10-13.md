# ALLRUNABOUT 인스타그램 시작 계획 — 러닝카드 중심

이전 계획: 사용자 방향 변경으로 발행 일정은 더 이상 적용하지 않는다. 새 기준은 [하루 2~3개 스타일 실험 계획](instagram-style-experiments-2026-10-13.md)이다.

작성: 2026-10-13. 상태: 계획 수립 및 AI 서브에이전트 검토 완료. 게시물 발행·계정 설정·사이트 변경은 아직 실행하지 않았다.

## 1. 확정 조건과 목적

- 광고비 0원. 주 4~6시간. 크루 단톡방·지인 동원은 실행 조건에서 제외.
- 채널은 신규 인스타그램 + 기존 allrunabout.com 사이트 두 개.
- 계정 아이디·현재 팔로워·게시물 유무는 미확인. 신규 계정/팔로워 0을 가정하고 계정 정보가 오면 링크와 설정만 보정한다.
- 일정은 준비 3~7일 + 공개 운영 4주. 준비에도 주 4~6시간 상한을 적용한다. 웹 개발 작업은 운영자의 콘텐츠 제작 시간과 별도 산정한다.
- 첫 달 목적은 실제 러너가 기능을 이해하고 결과를 만드는 흐름을 확인하고, 계정을 계속 볼 이유를 만드는 것이다.
- 인스타의 장기 약속: 러닝 기록을 이해하고 나에게 맞는 러닝화를 고르는 데 도움이 되는 정보.
- 첫 제품: 지난 28일 기록을 직접 입력해 유형·강점·다음 러닝 조언과 디지털 메달을 만드는 러닝카드.
- 첫 대상: 최근 한 달 달렸고 거리·횟수·페이스 등을 확인할 수 있는 취미 러너. 실제 달린 기록이 없는 사람에게 먼저 입력을 요구하지 않는다.

## 2. 현재 상태와 목표

GA4 읽기 조회: 2026-10-06~12, 완료 7일. 운영자 테스트를 별도로 제거하지 않은 관측값이다.

| 항목 | 관측값 | 의미 |
|---|---:|---|
| 사이트 활성 사용자 | 3,253명 | 관련 글이나 홈 홍보가 실제 이 모두에게 노출된다는 뜻은 아님 |
| 러닝카드 활성 사용자 | 22명 | 결과 공유 화면 방문도 포함될 수 있음 |
| 결과 조회 이벤트 사용자 | 12명 | 결과를 모두 읽었거나 만족했다는 뜻은 아님 |
| 공유 링크 열람 이벤트 사용자 | 1명 | 본인의 재열람도 포함될 수 있음 |

목표는 두 종류로 나눈다.

- 직접 실행할 목표: 게시물 8개, 재활용 스토리 8회, 프로필 고정 3개, 두 채널의 링크 동선 확인, 주간 기록 4회.
- 관찰할 가설: 공개 운영 28일 동안 결과 조회 사용자 50명, 구체적 사용 피드백 5건. 업계 기준·달성 보장이 아니다. 기간 전체를 한 번 조회하고 주별 사용자 수를 더하지 않는다.
- 팔로워 수와 좋아요 수에는 첫 달 필수 목표를 두지 않는다. 인스타 유입이 적으면 인스타의 효과가 확인되지 않았다고 기록하고 사이트 성과와 구분한다.

## 3. 메시지와 표현

중심 문구: **지난 28일의 러닝, 나만의 디지털 메달로 남겨보세요.**
보조 문구: **나는 어떤 러너일까? 기록으로 러닝 유형과 강점을 확인해보세요.**

기능 설명: “최근 28일 기록을 직접 입력하면 러닝 유형과 강점, 다음 러닝을 위한 조언이 나옵니다. 결과는 디지털 메달과 분석 카드로 저장·공유할 수 있어요.”

사용할 화면: 현재 제품의 실제 메달, 기록 입력, 분석 결과. 대표 메달 OG는 https://allrunabout.com/images/running-card-og-v2.png . OG 가로 이미지는 링크 미리보기 참고용이며 인스타 게시물 전체를 이 한 장으로 대체하지 않는다.

예시 기록은 이미지와 본문에 ‘예시 기록’이라고 표시한다. 실제 본인 기록은 ‘제 기록’으로 표시한다. 이용자 자료는 재게시 동의를 받은 경우에만 쓰고, 후기가 없으면 사례를 꾸미지 않는다.

실물 메달 배송, 자동 기록 연동, 성격·의학적 진단, 실측하지 않은 소요 시간은 약속하지 않는다. 메달별 우열이나 ‘이 메달을 얻으려면 무리해서 달려라’라는 접근도 사용하지 않는다.

## 4. 준비 기간 — 3~7일, 운영자 4~6시간

| 순서 | 할 일 | 완료 조건 | 담당 |
|---|---|---|---|
| 1 | 공개 인스타 계정·프로페셔널 대시보드 준비, 대표 이미지·소개글·프로필 링크 설정 | 다른 휴대전화/로그아웃 상태로 계정과 링크 확인 | 운영자, 40분 |
| 2 | 실제 기록 또는 명시적 예시로 모바일 입력부터 결과까지 1회 녹화 | 레거시 이미지 없음, 읽을 수 있는 결과·메달 확보 | 운영자, 40분 |
| 3 | 릴스 표지·캐러셀·스토리의 최소 템플릿 각 1개 준비 | 글자 가독성과 버튼/스티커 영역 확인 | 제작 지원 + 운영자, 40분 |
| 4 | 첫 게시물 2개 제작 | 첫 화면에 무엇인지 보이고 마지막 행동은 하나 | 운영자, 100분 |
| 5 | 사이트 진입점과 측정 준비 | 관련 글 3개와 홈 중 최소 1개 위치에서 링크 동작, 외부 출처 확인 | 개발 지원, 별도 작업 |
| 6 | 최종 확인·출시 일정 기록 | 본인 모바일에서 링크→입력→결과→이미지 열기 확인 | 운영자, 20분 |

사이트에 이미 러닝카드 메뉴·검색·푸터 링크는 있다. 출시 전에 추가할 홍보 진입점은 아직 구현하지 않은 작업이다. 대형 배너보다 관련 글 본문 뒤 작은 안내부터 적용하는 안을 우선한다. 사이트 작업이 지연되면 기존 메뉴 링크로 시작하되 추가 CTA 전후 관측 기간을 기록한다.

프로필 표시명 초안: `올런어바웃 | 러닝 기록·러닝화`
소개글 초안:

> 내 기록을 이해하고, 나에게 맞는 러닝화를 찾는 곳 🏃
> 지난 28일의 러닝으로 디지털 메달 만들기 🏅
> 아래 링크에서 러닝카드 시작 ↓

현재 제품은 ‘올런바웃’ 표기를 사용한다. 대외 브랜드 표기는 운영자가 선택한 한 가지로 프로필·제작물에서 통일하고, 이 계획 때문에 제품 이름을 임의 변경하지 않는다.

스토리 링크 스티커는 앱에서 사용 가능 여부를 확인한다. 없으면 ‘프로필 링크에서 만들기’로 안내한다. 고정 게시물은 제품 소개·사용법·브랜드 소개의 3개이며 2주에 걸쳐 준비한다.

## 5. 4주 편집 일정 — 주 2개, 총 8개

기본 발행은 화·금 저녁 8시(KST), 스토리는 발행일에 재사용한다. 운영하기 쉬운 가설 일정이며 최적 시간이라는 뜻은 아니다. 2주 동안 시간을 바꾸지 않고 콘텐츠 이해 여부부터 본다.

| 주/순서 | 형식 | 첫 화면 문구 | 넣을 내용 | 마지막 행동 |
|---|---|---|---|---|
| 1주 화 #1 | 12~20초 릴스 | 지난 한 달의 러닝이 메달이 된다면? | 현재 메달→입력→결과, 디지털 메달·직접 입력 명시 | 프로필 링크에서 만들기 |
| 1주 금 #2 | 4장 캐러셀 | 내 러닝 메달 만드는 순서 | 28일 기록 준비→입력→결과→이미지 공유 | 프로필 링크에서 만들기 |
| 2주 화 #3 | 화면 중심 릴스 | 저는 이런 러너로 나왔어요 | 운영자 실제 기록·결과에서 납득한 부분 1개. 없으면 예시라고 명시 | 프로필 링크에서 내 유형 확인 |
| 2주 금 #4 | 4장 캐러셀 | 러너를 위해 ALLRUNABOUT을 만들었습니다 | 만든 이유→러닝카드→러닝화 정보→앞으로의 콘텐츠 | 도움이 될 정보를 계속 보려면 팔로우 |
| 3주 화 #5 | 화면 중심 릴스 | 메달 아래, 다음 러닝을 위한 한 문장 | 실제 결과의 조언 1개와 읽는 법. 실제 실천 전후 효과를 꾸미지 않음 | 프로필 링크에서 내 조언 확인 |
| 3주 금 #6 | 4장 캐러셀 | 시작하기 전에 궁금한 3가지 | 기록 자동연동 아님/28일 항목/결과와 공유. 실제 질문 없으면 기본 안내로 표시 | 프로필 링크에서 만들기 |
| 4주 화 #7 | 화면 중심 릴스 | 지난 28일, 나는 어떤 러너였을까? | 첫 릴스의 후크만 바꿔 같은 제작자료 사용. 유효한 질문이 많이 생겼으면 대신 답변 영상 | 프로필 링크에서 만들기 |
| 4주 금 #8 | 4장 캐러셀 | 러닝화를 고르기 전, 내 러닝부터 | 거리·목적·발 맞음 등 실제 사이트 선택 정보. 러닝카드와 추천 기능이 자동 연결된다고 말하지 않음 | 프로필 링크의 사이트 정보 보기 |

릴스는 짧은 세로 영상, 캐러셀은 옆으로 넘기는 여러 장의 게시물이다. 지정 길이·장수는 제작을 단순하게 하는 기준이다.

첫 달은 러닝카드 6개 + 브랜드 소개 1개 + 러닝화 정보 1개. 둘째 달에는 댓글과 사이트 관심 주제를 보고 기록·훈련 정보와 러닝화 정보를 늘린다. 신화 인물을 하나씩 나열하는 계정으로 만들지 않는다.

제작 크기 권고: 캐러셀 1080×1350, 릴스·스토리 1080×1920. 중요한 글자는 가장자리와 앱 버튼 영역을 피해 중앙에 두고 최종 업로드 화면에서 확인한다. 유행 음악·촬영 장비·얼굴 출연은 필수가 아니다. 본인 화면 녹화와 읽기 쉬운 자막으로 시작한다.

## 6. 첫 게시물 — 바로 제작할 원고

릴스 #1 15초 예시:

| 시간 | 화면 | 자막 |
|---|---|---|
| 0~3초 | 실제 금빛 메달 크게 | 지난 한 달의 러닝이 메달이 된다면? |
| 3~8초 | 직접 입력하는 화면 2~3컷 | 지난 28일 기록을 직접 입력 |
| 8~12초 | 결과 이름·강점·조언 중 1개 | 나는 어떤 러너인지 확인 |
| 12~15초 | 메달과 계정명 | 디지털 메달 만들기 · 프로필 링크 |

캡션:

> 지난 한 달, 얼마나 빠르게 달렸는지 말고 어떻게 달렸는지도 궁금하지 않나요?
>
> ALLRUNABOUT의 러닝카드는 지난 28일 기록을 직접 입력하면 러닝 유형과 강점, 다음 러닝을 위한 조언을 보여줍니다.
>
> 기록으로 완성한 디지털 메달과 분석 카드는 이미지로 저장·공유할 수 있어요.
>
> 프로필 링크에서 나만의 러닝카드를 만들어보세요 🏅
>
> #러닝 #러닝기록 #러닝카드 #올런어바웃

캐러셀 #2:

1. 내 러닝 메달 만드는 순서 — 현재 메달 이미지.
2. 기록 앱에서 최근 28일 거리·횟수·평균 페이스 등을 확인하세요 — 자동 연동 없이 직접 입력합니다.
3. 내 기록을 넣고 러닝 유형·강점·조언을 확인하세요 — 실제 입력/결과 화면.
4. 디지털 메달과 분석 카드를 저장하거나 공유하세요 — 프로필 링크에서 만들기.

브랜드 소개 #4:

1. 러너를 위해 ALLRUNABOUT을 만들었습니다.
2. ‘내가 어떻게 달리는지’ 궁금할 때 — 러닝카드.
3. ‘어떤 러닝화를 고를지’ 고민할 때 — 비교·리뷰·추천 정보.
4. 기록을 이해하고 신발을 고르는 데 도움이 되는 정보를 올리겠습니다 — 팔로우 안내.

스토리 2종은 매주 본게시물에서 재사용한다:
- 메달 + ‘지난 28일, 나는 어떤 러너였을까?’ + 만들기 링크/프로필 안내.
- 입력 또는 결과 화면 + 이번 게시물의 한 문장 + 사용법 보기/프로필 안내.
- 2주차 금요일 스토리는 피드백 요청으로 대체: ‘만들어보셨다면 입력하면서 막힌 점 하나를 이 스토리에 답장해주세요.’ 기록이나 이미지를 보내달라고 요구하지 않는다.
- 3주차 금요일 스토리도 피드백 요청으로 대체: ‘결과에서 이해되지 않거나 내 러닝과 잘 맞았던 문장 하나를 알려주세요.’ 답장은 익명으로 주간 기록표에 요약하고, 재게시할 때 별도로 동의를 확인한다.

## 7. 사이트와 인스타 연결

사이트→러닝카드가 우선이며, 인스타 팔로우를 기능 사용의 조건으로 만들지 않는다.

관련 글 하단 문구:

> 지난 28일의 러닝, 디지털 메달로 남겨보세요.
> 내 기록으로 러닝 유형과 강점을 확인하고 나만의 메달을 만들어보세요.
> [내 러닝카드 만들기 →]

게재 위치는 최근 유입이 많은 글 중 러닝 기록·훈련·러닝화 선택과 관련된 3개를 실제 데이터로 고른다. 모든 페이지에 동일한 팝업을 넣지 않는다.

사이트→인스타는 작고 별도의 선택지:

> 러닝 기록과 러닝화 선택에 도움이 되는 정보를 인스타에서도 만나보세요.

인스타→사이트 기본 링크는 러닝카드로 직행한다. 링크 모음 페이지를 먼저 만들 필요는 없다. #8 게시 시 프로필에 사이트 정보용 링크를 추가하고 제목으로 구분한다. 기존 러닝카드 링크는 유지한다.

## 8. 주당 운영 — 약 4시간 40분, 상한 6시간

| 작업 | 시간 |
|---|---:|
| 월요일: 자료 확인·화면 녹화·게시물 2개 제작 | 150분 |
| 화·금: 게시와 재활용 스토리 | 합계 30분 |
| 주 4일: 댓글·메시지 답변, 관련 러닝 게시물에서 실제 대화 | 합계 40분 |
| 일요일: 지난 완료 7일 지표·피드백 정리 | 30분 |
| 오류 수정·여유 | 30분 |
| 합계 | 280분 |

교류는 관련 러닝 게시물에서 도움이 되는 질문·경험을 나누는 것이다. 복사 댓글·홍보 링크·무관한 태그를 반복하지 않는다. 운영자가 만들었다는 사실을 숨기지 않는다.

6시간을 넘으면 예비 릴스 편집을 줄여 캐러셀로 대체한다. 두 주 연속 넘으면 주 1개 본게시물+주 2회 재활용 스토리로 줄이고 변경 이유를 기록한다. 유료 도구·광고·대행은 첫 달 필요하지 않다.

## 9. 출처별 링크와 기록 방법

UTM은 링크를 어디에 올렸는지 GA에 알려주는 꼬리표다. 캠페인명은 네 주 동안 하나로 고정하고 소문자를 사용한다.

프로필용:
https://allrunabout.com/running-card?utm_source=instagram&utm_medium=social&utm_campaign=running_card_launch_202610&utm_content=bio

첫 스토리용:
https://allrunabout.com/running-card?utm_source=instagram&utm_medium=social&utm_campaign=running_card_launch_202610&utm_content=story_01

#8 게시 시 프로필에 추가할 사이트 정보 링크:
https://allrunabout.com/?utm_source=instagram&utm_medium=social&utm_campaign=running_card_launch_202610&utm_content=profile_site

스토리는 story_02~08로만 바꾼다. 개별 릴스가 프로필 방문을 거쳐 이 링크로 들어오면 어느 릴스 때문인지 직접 확정할 수 없다. 게시 후 변화는 관찰이지 인과 증명이 아니다.

사이트 내부에는 UTM을 넣지 않고 /running-card로 연결한다. 위치별 클릭은 별도 내부 클릭 이벤트가 준비됐을 때만 집계한다. 카드 공유 링크는 원래 UTM을 이어받지 않으므로 친구의 공유를 최초 인스타 게시물의 성과로 정확히 되돌려 계산하지 않는다.

주간 기록은 같은 요일, 지난 완료 7일로 조회한다. 인스타는 앱에서 제공되는 도달·프로필 방문·링크 관련 지표만 적고, 없는 항목은 0 대신 ‘미제공’으로 쓴다. 사이트는 GA4 출처/매체 및 러닝카드 방문·결과 이벤트 사용자 절대수를 별도로 적는다.

### 현재 측정의 한계와 준비 작업

- runner_analysis_started는 결과 공유 화면의 ‘내 메달 만들기’에만 발생한다. 일반 유입자의 시작률에 사용하지 않는다.
- step_number 등 맞춤 차원이 현재 GA에 등록돼 있지 않다. GA 관리→맞춤 정의에서 이벤트 범위 step_number 등록이 계획상 준비 작업이다. 아직 실행하지 않았다. 정확한 퍼널은 코드와 차원·집계 정의를 보완한 뒤 사용한다.
- 방문 활성 사용자와 결과 이벤트 전체 사용자는 정의·집단이 다르므로 12/22를 정확한 완료율로 표시하지 않는다.
- 이미지 저장 이벤트는 이미지 생성·저장 흐름 시도이며 실제 휴대전화 갤러리 저장 완료가 아니다.
- 링크 공유 시도는 실제 전송 완료가 아니다. 공유 열람에는 본인 열람이 포함될 수 있다.
- 운영자 테스트는 날짜·시간을 별도 기록하고 외부 사용자 성과로 단정하지 않는다. 내부 트래픽 필터 변경은 이번 계획에서 실행하지 않았다.

간단 피드백 질문:
1. 기록을 찾거나 입력하면서 막힌 부분이 있었나요?
2. 결과에서 내 러닝과 맞거나 이해되지 않은 문장은 무엇이었나요?
3. 이 메달이나 분석을 다른 사람에게 보여주고 싶었나요? 이유는요?

후기를 모집할 땐 사이트의 기존 문의/피드백 경로 또는 인스타 답장을 안내한다. 유효한 질문이 들어오면 안내글을 수정한다. 사진·닉네임·기록을 콘텐츠로 재사용할 때는 별도 동의를 확인한다.

## 10. 숫자를 보고 다음 주를 바꾸는 법

| 관측 | 다음 행동 |
|---|---|
| 첫 주 인스타 유입이 거의 없음 | 실패 단정 없이 사이트 진입점을 먼저 확인. 첫 화면에 메달·디지털·사용 목적이 보이는지 점검 |
| 사이트에서도 카드 방문 변화가 없음 | 실제 안내 노출 위치·모바일 가독성·링크부터 확인. 기존 사이트 전체 사용자에게 노출됐다고 가정하지 않음 |
| 방문은 늘지만 결과 사용자는 그대로 | 직접 모바일 사용 과정을 확인하고 기록 준비·입력 FAQ부터 보완. 현재 비정상 시작 이벤트로 완료율 추정하지 않음 |
| 결과는 늘지만 공유·후기가 적음 | 조언이 이해되는지 질문하고 저장/공유 조작의 불편 확인 |
| 한 게시물만 조회수가 큼 | 다른 문구로 한 번 더 재현. 조회수만으로 홍보 성공이라고 결정하지 않음 |
| 게시물 제작이 주 6시간을 초과 | 형식 단순화 또는 주 1개로 축소. 유지 가능한 방식 우선 |

2주 점검: 링크 동작, 실제 유입 유무, 댓글·피드백에서 가장 자주 나온 질문 1개, 다음 수정 1개.
4주 점검: 총 콘텐츠, 인스타 유입 세션, 기간 전체 결과 사용자, 구체적 피드백, 소요 시간. 인스타 효과와 사이트 효과를 나눠 평가한다. 유입이 너무 작으면 광고로 넘어가지 않고 잘 전달된 소재를 재사용해 한 주 더 관찰한다.

## 11. AI 서브에이전트 검토와 반영

마케팅 전략 역할, 제품·측정 검토 역할, 독립 실행 가능성 비판 역할로 검토했다. 사람 마케팅 전문가가 검증한 것으로 표시하지 않는다.

| 검토 | 지적 | 최종 반영 |
|---|---|---|
| 전략 | 메달만 반복하면 계속 팔로우할 이유가 약함 | 결과 해석·브랜드 소개·러닝화 정보 포함 |
| 전략 | 실제 금속 메달 지급·자동 연동 오해 | 디지털 메달과 직접 입력 문구 명시 |
| 측정 | 직접 시작 이벤트 누락·맞춤 차원 미등록 | 초기에는 방문/결과 절대수, 측정 준비 작업 분리 |
| 실행 비판 | 초보에게 제작·사이트개발·측정설정을 첫 주에 몰면 과부하 | 준비 기간 분리, 운영자 시간과 개발 지원 구분 |
| 실행 비판 | 유입 없는 신규 계정은 게시 횟수만으로 성장하지 않음 | 기존 사이트 진입점 우선, 관련 게시물 교류 루틴 |
| 전체 | 외부 반응·50명 목표는 통제할 수 없음 | 실행량 목표와 관찰 가설 구분 |
| 최종 실행 검토 | 후기 요청 날짜와 추가 프로필 링크 추적 누락 | 2·3주차 금요일 스토리로 피드백 요청, profile_site 추적 URL 추가 |

미확정 항목: 인스타 @아이디/현재 상태, 공개 브랜드 표기, 사이트 진입점의 실제 게시 위치. 계정이 없는 경우 계정을 만든 뒤 아이디만 넣으면 이 계획을 실행할 수 있다.
