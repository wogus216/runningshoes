# UI/UX 레퍼런스 라이브러리

이 문서는 사용자가 2026-10-11 대화에서 제공한 UI/UX 사이트·도구 목록을 보존한다. 목록은 대화에서 제공된 설명을 정리한 것이며, 모든 사이트를 직접 방문해 현재 운영 상태나 기능을 확인했다는 뜻은 아니다. 사용자 북마크와 추천 후보도 구분하지 않고 함께 수록했으므로, 구체적인 작업에 적용하기 전에는 해당 사이트와 사례를 다시 확인한다.

## 레퍼런스 기록 원칙

사이트 이름만 보관하지 말고 `참고할 문제`, `가져올 원칙`, `가져오지 않을 요소`, `적용 프로젝트`, `확인한 날짜`를 함께 기록한다. 사용자 제공 목록과 직접 검증한 사례는 구분한다. 이 라이브러리는 이번 대화에서 받은 목록을 다시 찾기 위한 색인으로 사용하며, 작업 요청이 오면 해당 목적에 맞는 후보만 추려 현재 상태와 실제 화면을 확인한다.

Saturday 프로젝트의 상세 참고 이유와 Pinterest 핀은 [saturday-crew-reference-guide.md](./saturday-crew-reference-guide.md) 및 관련 기획 핸드오프 문서를 함께 확인한다.
