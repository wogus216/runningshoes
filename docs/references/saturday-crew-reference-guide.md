# 쎄러데이 디자인 레퍼런스 가이드

쎄러데이와 시네마틱 러닝 페이지를 기획할 때 참고할 사이트 모음이다. 화면을 그대로 복제하지 않고, 먼저 해결할 문제를 정한 뒤 적합한 인터랙션·타이포그래피·구성 원칙만 가져온다.

## 레퍼런스 탐색 사이트

### Design Spells

- URL: https://designspells.com/
- 성격: 제품과 웹에서 발견되는 작고 인상적인 디자인 디테일 모음
- 주요 분류: Mobile, Desktop, Interaction, Apple, Animation, Motion, Transition, 3D
- 활용: 버튼 반응, 장면 전환, 스크롤 피드백, 작은 즐거움처럼 한 가지 상호작용을 정교하게 만들 때 우선 탐색한다.
- 주의: 여러 효과를 한 화면에 동시에 쌓지 않는다. 이야기나 사용성을 강화하는 디테일만 선택한다.

### Recent

- URL: https://recent.design/
- 성격: 최신 디자인 사례를 넓게 훑을 수 있는 시각 레퍼런스 아카이브
- 주요 분류: Web, Interface, Branding, Product, Typography, Motion, 3D, Editorial, Print, Packaging
- 활용: 프로젝트 초기에 전체 미감, 편집 구조, 타이포그래피, 3D 표현 방향을 비교할 때 사용한다.
- 주의: 썸네일의 분위기만 보고 결정하지 않는다. 후보의 실제 페이지와 모바일 동작을 확인한 뒤 적용 여부를 판단한다.

## 사용 순서

1. 현재 화면에서 해결할 문제를 한 문장으로 적는다.
2. Recent에서 전체 방향과 구성 후보를 넓게 찾는다.
3. Design Spells에서 필요한 인터랙션 디테일을 좁혀 찾는다.
4. 후보마다 `가져올 원칙`과 `가져오지 않을 표현`을 함께 기록한다.
5. 모바일 화면, 키보드 접근성, reduced-motion, 저성능 환경에서 다시 검증한다.

## 쎄러데이에 이미 적용한 1차 레퍼런스

- Nike Breaking2: 목표를 중심으로 도전·사람·과정·결과를 연결하는 스포츠 서사
- Tracksmith Journal: 러닝 기록이 시간에 따라 축적되는 편집형 아카이브
- 영화 《록키》의 박물관 계단 장면: 거칠고 인간적인 도달의 에너지
- Apple 웹 스토리텔링: 한 화면에 하나의 메시지를 두는 집중도와 스크롤 전환
- 영화 엔딩 크레딧: 이름과 역할이 올라간 뒤 남는 여운
