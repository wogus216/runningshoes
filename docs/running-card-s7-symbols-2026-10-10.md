# 러닝카드 S7 — 인물별 메달 표식 (2026-10-10)

## 결정과 기존 기록

사용자 확인: 인물을 메달 안의 표식으로 상징한다. 메달 중앙에는 해당 인물의 표식 하나를 크게 새기며, 인물명은 메달 밖의 제목에 표시한다.

- 원안: [2026-10-02 결과 설계](running-card-result-design-2026-10-02.md)의 D8·§5-3. 1단계는 가문 12개 표식과 이름, 2단계(S7)는 인물 36명의 고유 표식이었다.
- [S3 보고서](running-card-s3-report.md)는 1단계 구현과 S7 미구현을 기록했다.
- 10월 9일 메달 중심 결과 화면 적용은 S7을 구현하지 않았다. 계획이 취소된 근거는 없으며, 구현이 1단계에 머물러 있었다.
- `ceb5538`의 분석 카드 메달 미리보기 추가도 인물별 표식 구현을 대신하지 못했다. 이번 변경에서 S7을 실제 연결했다.

## 구현

`medal3d-character-signs.js`의 인물 ID별 Canvas 도형을 기존 마스크·부조·금속 맵 생성 경로에 연결했다. 워커 요청에 인물 ID를 전달하고, 3D 메달·2D 대체 화면·분석 미리보기·공유 이미지가 같은 표식 맵을 사용한다. 스크린리더 설명과 각인 알림에도 인물과 표식 이름을 제공한다.

표식은 원안 §5-3의 제안을 기준으로 구현했다. 신화적 속성의 시각적 해석이며 러닝 유형 판정은 그대로 사용한다.
