# 프로스펙스 서촌 전시 페이지 시안

〈Wish You Were Here〉 전시를 소개하는 로컬 시안입니다. 현재 편집 중인 페이지는 [`direction/index.html`](direction/index.html)입니다. 브라우저에서 파일을 열면 됩니다.

- `direction/`: 현재 페이지와 디자인 기록
- `assets/`: 건물 외관 및 시대별 거리 사진
- `planning/photos/`: 직접 촬영한 전시 사진
- `planning/`: 사진 선정 메모와 초기 스토리보드

이 브랜치는 다른 컴퓨터에서 작업을 이어가기 위한 보관용입니다. 사이트를 배포하지 않았으며, 이 브랜치의 Vercel 자동 배포도 비활성화했습니다.
