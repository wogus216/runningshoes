## ⑥ 상시 — 낡은 접수 상태 스캔

`npm run validate` 는 `registrationEnd` 가 **있는** 대회만 검사한다. 없는 대회는 몇 달이고
"접수중"으로 남는다. 월 1회 정도 이걸 돌린다:

```bash
npx tsx -e "
import { marathonEvents } from './src/lib/data/marathon/index';
const T=new Date().toISOString().slice(0,10);
for(const e of marathonEvents as any[]){
  if(e.status==='접수예정' && e.registrationStart && e.registrationStart<T) console.log('[A]',e.id,e.registrationStart);
  if(['접수예정','접수중'].includes(e.status) && e.registrationEnd && e.registrationEnd<T) console.log('[B]',e.id,e.registrationEnd);
}
"
```

⚠️ **잡혔다고 바로 뒤집지 말 것.** 도쿄·오사카는 날짜가 정확했고 `status` 만 낡은 경우였다.
그리고 마감 뒤 러너에게 필요한 건 "마감"이 아니라 **다음 관문**이다(추첨 결과일·결제 기한).
